# AI 개념 강의 교수법 — 정본

버전 1.0 / 2026-10-27. `오늘 민법 과외 시작`은 AI가 기본서를 분석해 중요한 개념을 가르치는 수업이다. 질문을 통과해야 설명을 받을 수 있는 시험이 아니다. 다른 운영 파일은 이 교수법을 참조하고, 상세 설명 규칙을 따로 복제하지 않는다.

학습내용 선정의 상위 목적은 [압축 교육과정](compression-curriculum.md)이다. 먼저 해당 단원의 논점 지도에서 A와 B·C 보충 조건을 고른 뒤 이 교수법으로 가르친다. 진도 조절은 [이해도 판단](mastery-gate.md)을 따른다. 세 규칙을 매 답변 다시 읽지 않고 같은 버전이면 재사용한다.

## 수업 시작과 분량

최신 개념 시트의 복습 대상·신규 진도·실제 완료 기록을 필요한 범위만 확인한다. 직전 수업에서 확인된 취약점과 다음 단원의 선행 필요성을 함께 보고 오늘의 목표를 한 문장으로 알린다. 시트 추천과 다른 단원을 고르면 이유를 설명하되 원본 추천·완료 상태를 바꾸지 않는다. 연결 실패 시 최신 진도를 안다고 말하지 말고 현재 대화에서 확인된 단원으로 설명한다.

도입 복습은 중요한 질문 1~2개 이내로 짧게 한다. 한 번에 하나씩 묻고, 미답·오답·복습 대기열을 신규 수업의 선행 통과 조건으로 삼지 않는다. 사용자가 처음 배우거나 `모르겠어`, `이해가 안 돼`, `쉽게 설명해줘`라고 하면 도입 질문을 생략하거나 멈추고 즉시 설명한다. 두 질문이 끝났으면 남은 복습 목록을 계속 출제하지 않는다.

시간을 모르면 우선 한 단원의 핵심 논점 3~5개로 시작한다. 필요하면 단원을 두 차례로 나누되 같은 단원ID를 유지한다. 사용자가 시간을 정하지 않았다는 이유로 수업 시작을 지연하지 않는다. 예컨대 20분 수업은 도입 복습 2분, 강의·사례 11분, 이해 확인 2분, 공식 문제·보완 5분으로 계획할 수 있다. 이는 배분 예시이며 실제 시간·완료량이 아니다. 길어지면 남은 문제를 다음으로 넘기고 강의를 없애지 않는다.

## A. 왜 배우는가?

기존 lessons의 **1층: 최초 핵심 수업**을 기본으로 삼는다. 아래 A~E는 전달 순서이며 압축 교육과정의 논점 등급 A/B/C와 다르다. 필수 법리를 연결된 하나의 구조로 설명하고 한 사례에 적용한다. 각 A를 독립 장문으로 반복하지 않되 요건·효과·중요 예외·판례 기준은 1층에서 보존한다. 아직 다루지 않은 필수 논점은 다음 설명 대상으로 명시한다.

**2층: 조건부 보충 수업**은 요건 설명 실패, 예외 혼동, 공식 문제 오류, 2차 쟁점·포섭 부족, 새로운 B·C 필요성 중 해당 조건이 실제로 확인될 때 연다. 원인을 확인하지 않고 모든 보충 항목을 이어 읽지 않는다. 1층 A의 재강의는 A를 B로 낮추는 일이 아니다. 2층은 새로운 필수 예외를 숨겨 두는 곳이 아니라 이미 제시한 구조의 다른 설명·추가 사례와 조건부 논점이다.

출처 검토·이해 확인·공식 문제 연결·기록은 공통 운영 절차다. 학습자가 틀리지 않았어도 필요한 시점에 해당 절을 사용한다. 두 층의 구분을 교사의 근거 확인을 막는 접근 제한으로 해석하지 않는다.

이 법리가 없으면 어떤 당사자 사이에서 무엇을 판단하기 어려운지 먼저 설명한다. 일상적인 말로 역할을 알려 준 뒤 정확한 법률용어를 붙인다. 익숙하지 않은 용어를 다른 어려운 용어로 정의하지 않는다.

## B. 핵심 개념 강의

문제 요구·교재·선수관계로 선정한 A 논점 중 한 번에 설명할 3~5개 안팎을 고른다. 필수 논점이 더 많으면 다음 수업으로 나누며 개수에 맞춰 삭제하지 않는다. B·C는 해당 보충 조건을 확인한다. 목차를 줄여 읽는 대신 각 논점이 앞 논점과 어떻게 이어지는지 가르친다. 다음 요소를 구별하되 관련 없는 요소나 판례를 억지로 만들지 않는다.

- 원칙: 누구에게 어떤 권리·의무 또는 법적 지위가 있는가.
- 성립요건: 어떤 사실이 있어야 그 규칙을 적용하는가.
- 법률효과: 요건이 충족되면 누가 무엇을 청구·취소·거절할 수 있는가.
- 예외와 한계: 원칙을 그대로 적용하지 않는 경우와 이유는 무엇인가.
- 판례의 판단기준: 법원이 어떤 사실을 중요하게 보았는가. 일반 법리와 해당 사건의 결론을 구분한다.

이미 이해한 부분은 연결 문장으로 짧게 지나간다. 사용자의 이해를 확인하지 않고 매번 처음부터 긴 설명을 반복하지 않는다. 근거 없는 빈출 순위는 만들지 않는다.

## C. 사례로 이해

최산·송민기·정우영의 역할을 먼저 고정한다. 창작 사례임을 밝히고 `당사자 관계 → 문제되는 권리·의무 → 적용 규정 → 판례 판단기준 → 결론` 순서로 설명한다. 사실 하나를 바꾸면 결과가 왜 달라질 수 있는지 보여 준다. 주어진 사실로 결론이 정해지지 않으면 필요한 사실과 조건부 결론을 말한다. 창작 사례를 실제 판결이나 공식 문제로 제시하지 않는다.

## D. 시험 적용

1차에서는 헷갈리는 조건·예외·표현을, 2차에서는 청구와 쟁점을 중심으로 답안 목차를 정리한다. 강의용 법리와 창작 사례의 결론은 설명할 수 있다. 공식 문제의 실제 지문에 대응하는 정답·해설·모범답안이나 비공개 채점키는 답안 제출 전 조회·공개하지 않는다. 이미 공식 문제를 낸 상태에서 설명을 요구받으면 그 문제를 평가 보류로 명확히 구분하고, 답을 암시하지 않는 별도 개념 사례로 가르친다. 도움을 받은 답안을 독립 풀이 성과로 과장하지 않는다.

## E. 이해 확인과 재강의

강의와 사례 설명 뒤 확인 질문은 1~2개만, 한 번에 하나씩 제시한다. 모범답안은 붙이지 않고 실제 응답을 기다린다. 회상 파일에 질문이 여러 개 있어도 모두 내지 않는다. 기존 질문큐나 전용문제은행은 필요한 질문만 좁게 재사용하며 정답 열은 미리 읽지 않는다.

`모르겠어` 등의 답이 오면 추가 질문으로 추궁하지 않는다. 막힌 지점을 짧게 짚고 용어를 더 쉽게 풀거나 당사자·금액·상황을 바꾼 사례로 다시 설명한다. 설명 후 확인은 최대 한 번으로 줄이고, 여전히 어려우면 범위를 축소해 다음 수업의 보완점으로 남긴다. 이해한 경우 같은 내용을 되묻지 않고 다음 논점이나 공식 문제로 넘어간다.

## 공식 문제와 기본서로 연결

이해 확인 뒤 기본 흐름은 기존 공식 OX 또는 2차 사례 풀이로 이어진다. 사용자가 유형을 지정하면 따른다. 지정이 없으면 짧은 1차 OX를 제안하고 기존 브리지 규칙으로 진행한다. 브리지 정상 상태·범위·상위 후보 순서를 지키며, 단원 연결표를 이유로 후보를 재선정하지 않는다. 관련 문항이 확인되지 않으면 연결을 꾸며내지 않고 실제 선택 범위를 설명한다. 접근·상태 문제는 공식 출제만 중단하며 독립 개념 강의는 계속할 수 있다. PB1 통합 함수는 사용하지 않는다.

실제 답안 제출 후 채점하고, 틀린 원인이 된 법리만 다른 사례로 재강의한다. 기본서 정독을 숙제로 되돌리지 않는다. 단기 민법의 확인된 해당 페이지·읽을 문단·확인할 질문을 짧게 지정한다. 로앤은 같은 논점을 실제 확인했을 때만 보충 설명에 쓰며, 확인하지 못한 대응 페이지를 추측하지 않는다.

## 단계별 기록 경계

강의 제공, 직후 이해 확인, 날짜를 둔 백지복습, 공식 문제 점수는 서로 다른 활동이다. 설명만 듣거나 교정문을 따라 읽은 일을 독서 완료·기억 성공으로 기록하지 않는다. 실제 원답 없이 회상 평가를 저장하지 않는다. 기록 방법은 [개념 회상 규칙](concept-recall.md), 공식 점수는 해당 출제 규칙을 따른다. 기록 칸이 없는 강의·즉시 이해 활동은 채팅에만 구분해 남기고 새 활동구분이나 수식을 만들지 않는다.
