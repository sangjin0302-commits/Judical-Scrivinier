# 민법 2차 공식 사례

1. 사용자 범위·유형·사례 수·연도/회차/문 번호·안정키·미풀이/오답/저득점/복습기한/원문변경 조건을 PostgreSQL 문제은행에 적용한다. 사례를 고르면 해당 사례의 모든 소문항을 함께 출제한다. 진행 중 세트 중복을 피한다.
2. 문제·안정키·소문항 배점만 제시한다. 모범답안·채점기준·해설은 원답 확정 전 조회·공개하지 않는다.
3. 실제 작성한 소문항 원답을 글자 그대로 불변 저장한다. 빠진 소문항은 `UNSUBMITTED`로 구분하며 가짜 빈 원답을 만들지 않는다. 실제 `모르겠다` 답안은 `SUBMITTED`지만 실질 무응답으로 0점이다.
4. 원답 확정 후 해당 세트의 공식 모범답안·채점기준만 조회한다. 중복 없는 필수 의미요소를 쟁점·법리·요건·포섭·결론으로 분해하고 원답과 의미 단위로 비교한다. 완전 1, 부분 0.5, 누락·오류 0. 법률적으로 동등한 표현을 인정한다.
5. 인정 요소 합계 ÷ 필수 요소 수 × 소문항 최대 배점으로 **AI 학습평가 점수**를 계산한다. 원계산값과 두 자리 표시값, 요소별 근거·감점 이유를 보존한다. 공식 채점자가 부여한 점수로 표시하지 않는다. 쟁점·목차·법리·판례·포섭·결론·표현 7요소는 별도 진단이며 점수에 중복 가산하지 않는다.
6. 채점 기록은 소유권·원답 불변·멱등성·트랜잭션을 검사한다. 같은 평가 재시도는 같은 결과, 바뀐 평가 제출은 거부한다. 합성 답안은 사용자 성과로 기록하지 않는다.

운영 Google Sheets·Docs·Apps Script는 변경하지 않는다. 기존 PREPARED 원답은 수정하지 않고 의미 판정 인수시험 전 채점 완료로 바꾸지 않는다.
