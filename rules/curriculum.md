# 진도와 분량 결정

가르치는 방식과 일일 흐름은 [교수법 정본](teaching-method.md)을 따른다. 이 파일은 단원 선택과 분량만 정한다. 기존 단원ID를 사용하며 개인 진도·복습일은 시트에서 읽고 GitHub에 복제하지 않는다.

내용 선정은 [압축 교육과정](compression-curriculum.md)이 우선한다. 단원 목차 순서만 따라 같은 시간을 배분하지 않는다. 해당 단원의 논점 지도에서 시험 요구·필수 선수관계가 확인된 A부터 고르고, B·C는 보충 조건에 따라 적용한다. 지도에 없는 단원은 근거를 확인해 준비하고 미분류를 생략 허가로 쓰지 않는다. 잠정 진행·재강의·미확인 영역의 처리는 [이해도 판단](mastery-gate.md)을 따른다.

오늘의 복습 대상·신규 추천·실제 완료 범위를 함께 확인한다. 도입 복습은 중요한 1~2개 질문으로 제한하고 남은 대기열과 무관하게 핵심 강의를 시작한다. 중요도는 실제 취약점과 다음 단원의 선행 필요성에 근거한다. 공식 출제 후보 순서를 바꾸는 기준으로 쓰지 않는다.

신규 또는 이해가 부족한 단원 하나를 AI가 선정하고 이유를 짧게 말한다. 시트 추천과 실제 진행 범위를 기본으로 삼되 막힌 선행 법리는 필요한 부분만 먼저 설명한다. 이전 단원 전체를 다시 통과해야 한다는 조건은 만들지 않는다.

신규 2단원·복습 3단원은 기존 설정값이지 반드시 끝낼 수업 할당량이 아니다. 시간을 알면 강의·사례에 가장 큰 몫을 배정한다. 시간을 모르면 한 단원의 핵심 논점부터 가르치고 실제 반응에 맞춰 분량을 조절한다. 도입 복습으로 신규 수업 시간을 모두 소진하지 않는다.

긴 단원은 같은 ID 안에서 논점별로 나눈다. 다룬 범위·남은 논점·다음 시작점을 구분하고 부분 수업을 단원 전체 완료로 기록하지 않는다. 설명만으로 선수단원 통과나 기억 성공을 부여하지 않는다.

상세 강의가 없으면 해당 교재를 확인한 뒤 정본으로 준비한다. 출제빈도·취약성·선수학습 추천·연결 검증 상태를 구별하며 근거 없는 빈출 등급을 만들지 않는다.
