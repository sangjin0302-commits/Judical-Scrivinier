# 진도 결정

전체 단원은 curriculum/units-index.csv의 기존 ID를 사용한다. 개인의 현재 진도와 복습일은 시트에서 읽으며 GitHub 색인에는 복제하지 않는다.

오늘 학습은 기한 도래 복습 → 확인된 취약 개념 → 신규 진도 순으로 준비한다. 복습만으로 시간을 모두 소진하지 않도록 사용 가능한 시간 안에서 신규 수업량을 조정한다. 설정의 신규 2단원·복습 3단원은 현재 설정값일 뿐 사용자의 시간 확인 없이 고정 성과를 약속하지 않는다.

신규 수업은 핵심 논점·권리의 주체와 상대방·성립요건·효과·예외·짧은 예시를 설명한다. 이어 책을 덮고 회상하고, 공식 문제는 기존 브리지 절차로 출제한다. 틀린 부분만 기본서 해당 페이지로 돌아간다.

선수학습 추천은 교육과정 설계 판단이다. 출제빈도·사용자 취약성·검증된 문제 연결과 구별한다. 모든 단원의 상세 강의가 준비되었다고 말하지 않는다.

평가 전에 질문의 정답을 보여주지 않는다. 이미 설명한 내용을 회상하는 경우 즉시 회상과 날짜를 둔 복습을 구별한다. 설명만으로 학습 성공을 부여하지 않는다.
