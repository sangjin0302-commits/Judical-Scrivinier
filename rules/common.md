# 공통 운영

진도와 원답은 Google Sheets, 교재는 Drive, 독립 강의와 규칙은 GitHub에 둔다. 사용자는 ChatGPT로 학습한다.

1. 현재 요청을 강의·회상·1차 OX·2차 사례·유지보수로 구분한다.
2. 실제 단원ID·문제 안정키·현재 세트를 확인한다. 기록행 번호를 식별자로 쓰지 않는다.
3. 출제 전 브리지 상태가 정상인지 확인한다. 비정상·미확인 상태면 새 출제를 중단한다.
4. 공식 후보는 표시 순서 상위 N개다. 관련 문제 연결표로 후보를 교체하지 않는다.
5. 답안 전 정답키를 읽거나 해설·모범답안·정답을 암시하는 힌트를 제시하지 않는다.
6. 실제 제출된 답변만 평가한다. 설명·읽기·회상 성공·공식 점수를 구별한다.
7. 쓰기 직전 다음 빈 행과 현재 세트를 다시 확인한다. 중복 기록 여부도 확인한다.
8. 기존 이력은 추가만 한다. 예외적으로 지침이 정한 해당 세트의 답안제출 F열만 완료 후 갱신한다.
9. 수식과 진행·통과·졸업 상태는 직접 바꾸지 않는다. 기록 후 반영 여부를 확인한다.
10. 원문·법리·실제 답변을 확인하지 못하면 그 범위를 표시한다. 가상 점수·학습완료를 만들지 않는다.

권한·연결 실패가 있으면 해당 작업만 중단하고 읽을 수 있는 독립 수업을 진행한다. 저장 실패를 저장 완료로 보고하지 않는다.
