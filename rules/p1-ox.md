# 1차 OX

기존 상세 지침 v3와 고속 추가규칙 v2의 비충돌 부분을 적용한다. 아래는 기존 브리지의 기본 경로이며 통합 브리지 자동 전환을 허용하지 않는다. 통합 경로는 `docs/bridge-alignment.md`에 승인 및 계약 확인 근거가 있을 때만 적용한다.

## 출제

1. GPT브리지_1차 B5가 정상인지 확인한다. B7 출제모드, B8 범위, B9 문항수, B10 새 셔플시드를 설정한다. 별도 요청이 없으면 실제 학습 완료가 확인된 누적 범위에서 기본 10문항을 출제한다. 이를 법전 전범위로 해석하지 않는다. 사용자 지정 문항수·대상범위·출제모드를 우선한다.
2. A17:H136 후보 표시 순서 상위 N개를 선택한다. 선택칸 K17:K56의 용량을 넘으면 임의 확장하지 않는다.
3. K17:K56에 안정키를 쓰고 남은 선택칸을 비운다. 필요한 L:S를 읽어 안정키·본문·S열 기준시각을 확인한다.
4. `P1-YYYYMMDD-HHMMSS` 세트ID를 만들고 기존 중복이 없는지 확인한다. B11이 가리키는 세트관리 다음 빈 행의 A:G에 세트ID/출제일/문항번호/안정키/공개 예/답안제출 아니오/기준시각을 묶음 추가한다.
5. 정답 없이 문제를 제시한다. 성공한 출제·기록만 완료로 알린다.

범위와 비중은 고속 v2를 따른다. 총칙 3·물권 7은 당시 설정이며 영구 비율이 아니다. 최신 학습 영역은 기본 6~7문항, 이전 영역은 3~4문항을 목표로 하되 실제 진도·후보 수·사용자 요청에 맞춘다. 장번호를 과거 값으로 고정하지 않는다. 부분 학습 장의 쪽수 필터가 지원되지 않으면 한계를 알리고 후보를 건너뛰지 않는다.

기존 브리지에서 여러 영역을 섞을 때는 영역별로 순차 설정하고 각 후보 상위 N개를 선택하여 별도 정식 세트ID로 먼저 등록한다. 사용자에게는 연속 번호로 제시하고 전체 번호↔세트별 번호↔안정키 대응을 보존한다. 통합 함수의 현재 계약과 접근 경로가 검증된 경우에만 단일 세트 경로를 사용한다.

## 제출 후

답안 수·O/X 형식·세트별 번호와 안정키 대응을 먼저 확인한다. 그 후에만 GPT채점키_1차의 해당 선택 행을 조회한다. 마지막 브리지 선택에서 밀려난 앞 묶음은 답안 제출 후 해당 안정키의 비공개 채점키 행만 좁게 조회한다. 정답키 전체는 읽지 않는다. 정답 1점·오답 0점으로 일괄 채점한다.

B12 기준 OX정답키 A:G, B13 기준 풀이이력 A:L의 다음 빈 행에 기존 헤더에 맞춰 묶음 추가한다. OX정답키 H와 풀이이력 M:Q 수식은 쓰지 않는다. 기록 확인 후 해당 세트관리 F열만 예로 바꾼다. 오답만 짧게 교정한다.

빈 키·불일치·부분 저장은 실패 상태로 보존한다. 답안 없이 성능 시험용 정답 조회 또는 가짜 풀이이력 생성 금지.
