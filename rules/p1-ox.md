# 민법 1차 공식 OX

1. 사용자 요청의 범위·유형·문항 수(기본 10, 최대 40)·연도/회차/문 번호·안정키·미풀이/오답/저득점/복습기한/원문변경 조건을 가능한 DB 메타데이터에 한해 적용한다. 근거가 없는 속성은 추측하지 않고 실패로 알린다.
2. PostgreSQL의 게시 문제 중 현재 원문 버전과 검증된 활성 암호화 정답키가 있는 항목만 고른다. 같은 사용자에게 진행 중인 세트의 문제는 중복 출제하지 않는다. 출제·세트 기록은 한 트랜잭션과 requestId 멱등성으로 처리한다.
3. 문제·안정키만 제시한다. 답안 제출 전 정답·해설·채점키를 읽거나 공개하지 않는다.
4. 출제된 세트의 문항 수만큼 실제 O/X 답안을 받아 원답을 불변 기록한 뒤, 해당 세트에 묶인 정답키를 대조한다. 정답 1, 오답 0과 문제별 풀이이력을 한 트랜잭션으로 저장한다.
5. 같은 답안 재시도는 같은 결과를 반환한다. 다른 답안 재제출·타인 세트 접근·부분 실패는 거부 또는 롤백한다.

기존 Google Sheets 사용자 선택권은 유지하되 내부 시드·셀 수식은 복제하지 않는다. 운영 Sheets·Docs·Apps Script 원본에는 쓰지 않는다. 합성 답안을 실제 학습 성과로 기록하지 않는다.
