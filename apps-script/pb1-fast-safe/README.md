# PB1 Fast/Safe v2

운영 원본에 배포하지 않은 테스트 사본 전용 소스다. `PB1F_TEST_SPREADSHEET_ID` 스크립트 속성에 별도 사본 ID를 넣어야 하며, 운영 원본 ID는 코드가 거부한다.

- 출제: 활성 `1차통합설정`을 읽고, 각 범위의 기존 `GPT브리지_1차`가 표시한 상위 N개를 그대로 선택한다. 답안 전 채점키를 읽지 않는다.
- 채점: 제출된 세트의 안정키를 선택란에 복원한 뒤 `GPT채점키_1차`의 선택 40행만 읽는다. 전체 키 탭을 읽지 않는다.
- 안전: ScriptLock, 요청 재시도 멱등성, 중복 제출 대조, append-only 부분 실패 복구, 최종 행·값·수식 검증 뒤 제출 표시를 사용한다.
- 소유권: Apps Script의 임시 활성 사용자 키로 출제 요청·세트·답안 예약을 묶는다. 다른 사용자 세트의 복원·채점을 거부한다. 웹앱 배포 방식에서 사용자별 키가 실제로 분리되는지는 독립 프로젝트 인수시험에서 확인해야 한다.
- 재시도: 완료 매핑은 공개 행 재검증 뒤에만 저장한다. 쓰기 도중 실패한 요청은 별도 보류 상태로 같은 세트를 복구하며, 화면은 성공할 때까지 같은 `requestId`를 재사용한다.
- 화면: Apps Script HTML Service 한 화면이다. 별도 서버·유료 API가 없다.

테스트 사본에서 후보 동등성, 키 비노출, 동시 제출, 단계별 실패 후 재시도를 통과하기 전 운영 승격 금지.

로컬 정적·순수 로직 검사는 `node --test tests/pb1_fast_safe_node.test.js`로 실행한다. 기존 Python 합성 검사는 Google 서비스와 분리된 계약 모델이다. 실제 Apps Script 동시성·수식·권한 검증을 대신하지 않는다.
