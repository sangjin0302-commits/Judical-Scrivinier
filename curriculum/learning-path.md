# 민법 학습 경로

기준일: 2026-10-27. 원본은 개념 관리표의 `개념_단원마스터`다. 이 문서는 학습 계획이며 실제 성취 기록이 아니다.

## 전체 순서

| 단계 | 범위 | 단원 수 | 학습 목표 |
| --- | --- | ---: | --- |
| 1 | 민법총칙 | 46 | 권리의 주체·객체·변동을 구분하고 뒤 단원의 용어를 익힌다. |
| 2 | 물권법 | 50 | 물건을 둘러싼 권리관계와 당사자별 청구 구조를 정리한다. |
| 3 | 채권법 | 86 | 계약과 그 밖의 채권 발생원인, 이행·불이행·소멸을 연결한다. |
| 4 | 가족법 | 58 | 신분관계와 상속관계를 나누어 사례의 검토 순서를 익힌다. |

기존 학습순서 1~240을 기본으로 삼는다. `suggested_previous_unit`은 앞 단원을 찾는 안내값이며, 엄격한 선수학습 조건이 아니다. 이미 아는 단원은 실제 회상으로 확인하고 필요한 부분만 보완한다. 단원ID는 바꾸지 않는다.

## 하루 운영

오늘의 대상은 원본 `개념_오늘학습`에서 읽는다. 기본 설정은 신규 2단원·복습 3단원이지만, 이 저장소의 숫자로 원본 설정을 덮어쓰지 않는다. 복습 대기열을 모두 끝내야 신규 학습에 들어가는 조건은 두지 않는다. 한 단원이 길면 같은 단원ID 안에서 수업을 나누고, 부분 학습을 전체 완료로 기록하지 않는다. 수업의 세부 기준은 [교수법 정본](../rules/teaching-method.md)을 따른다.

1. 오늘의 실제 신규·복습 대상을 확인한다.
2. 짧은 복습 1~2개로 기억 상태를 확인한 뒤 신규 또는 설명이 부족했던 단원으로 넘어간다.
3. AI가 핵심 개념을 가르치고 짧은 사례로 적용 과정을 설명한다.
4. 이해 확인 질문 1~2개를 묻고 실제 답변을 기다린다.
5. 공식 문제는 해당 브리지의 기존 절차로 출제한다. 연결표로 후보 순서를 바꾸지 않으며, 답안 제출 전 채점키를 읽지 않는다.
6. 답변에서 드러난 부족한 법리만 다시 설명하고 다음 진도를 정한다.

강의 직후의 이해 확인과 시간이 지난 뒤의 회상은 구분한다. 설명을 들었거나 즉시 답했다는 사실만으로 기억 성공·회독 완료를 기록하지 않는다. 실제 회상 원답 없이 회상 평가·기억 성공을 만들지 않는다. 독서는 사용자가 실제로 읽었다고 확인한 내용을 기존 규칙에 따라 기록한다. 기록 조건과 위치는 기존 원본 규칙을 따른다. 복습 간격은 기존 수식의 1·3·7·21·60일 규칙을 유지한다.

학습시간은 수업 분량을 조절하는 제안값이다. 예상 시간만으로 이해도나 완료일을 정하지 않는다. 실제 답변과 사용한 시간을 보고 다음 수업의 범위를 조절한다.

## 시험 요구에 따른 논점 우선순위

[논점 지도](issue-map.csv)는 7단원의 시범 분류와 나머지 233단원의 미분류 상태를 구분한다. A는 필수 선수 개념이나 실제 문제의 요구를 근거로 배우고, B는 적용 또는 취약점이 드러났을 때 보충한다. C는 근거를 확인한 배경 논점만 조건부로 유예한다. 새로운 예외·판례나 확인하지 않은 원문을 자동으로 C에 넣지 않는다.

등급별 논점 수를 같게 맞추지 않는다. 분량·AI의 직감·검증하지 않은 출제빈도로 분류하지 않으며, 직접 문제 관찰과 교육설계상 선수 관계를 구별한다. [시험 요구 분석](../docs/exam-demand-evidence.md)과 [비교 실험안](../docs/compression-pilot-plan.md)을 함께 참고한다. 전체 시험 역산과 시간 절감 효과는 아직 검증되지 않았다.

학습 순서는 다음 근거를 구분해 판단한다. 근거 없는 출제빈도·빈출 등급은 만들지 않는다.

- 선행 필요성: 뒤 단원의 용어를 이해하는 데 필요한 개념인지 확인한다.
- 공식 문제 연결: 기존 연결표에 등록된 사실과 그 검증 상태를 함께 확인한다.
- 공통 활용: 1차의 법리 구별과 2차의 사례 설명에 어떻게 쓰이는지 수업에서 확인한다.
- 개인 취약점: 해당 세션에서 원본 이력을 필요한 범위만 읽는다. GitHub에는 개인 이력을 옮기지 않는다.
- 구조적 중요성: 여러 단원의 권리관계를 설명하는 개념인지 판단하고, 판단 이유를 밝힌다.

2단원의 수업 흐름을 개편했고, 이번에는 기존 7단원 모두 논점 지도에 맞춰 압축 수업을 적용한다. 나머지 233단원은 색인과 수업 목표까지 준비했다. `core_topics`는 기존 목차·구간명이며, 각 구간의 세부 법리를 전수 검증했다는 뜻이 아니다. 상세 강의가 없는 단원은 오늘학습 대상으로 정해졌을 때 필요한 원문을 확인하고 준비한다. 적용 범위와 점검 기준은 [교수법 개편 보고](../docs/teaching-redesign.md), 대화 예시는 [시범 수업](../docs/teaching-demo.md)을 참고한다.

색인의 `recall_question_ids`는 원본 개념 질문큐에 있는 기존 질문ID다. `recall_path`의 시범 질문은 별도로 작성한 연습 질문이므로 두 목록을 같은 문항으로 간주하지 않는다.

## 단계별 확대 조건

자료를 만들었다는 사실과 실제 수업 성과를 구분한다. 확대 여부는 [실험안](../docs/compression-pilot-plan.md)의 사전 기준과 실제 답변·총시간·지연 관찰을 확인한 뒤 정한다. 현재 성과는 미측정이며 다음 단계로 자동 진입하지 않는다.

## 보충교재 사용

단기 민법의 순서와 단원ID를 유지한다. 보충교재는 같은 주제를 다른 설명으로 확인할 때만 좁게 읽는다. 두 교재의 편제 순서는 다르므로 장 번호로 연결하지 않는다. 대응 상태는 `sources/textbook-mapping.csv`에서 확인한다. 차이가 발견되면 자료별 설명을 구분하고, 현행 법령·판례를 확인하기 전 합성하거나 공식 정답을 바꾸지 않는다.
