# 민법 학습 경로

기준일: 2026-10-27. 원본은 개념 관리표의 `개념_단원마스터`다. 이 문서는 학습 계획이며 실제 성취 기록이 아니다.

## 전체 순서

| 단계 | 범위 | 단원 수 | 학습 목표 |
| --- | --- | ---: | --- |
| 1 | 민법총칙 | 46 | 권리의 주체·객체·변동을 구분하고 뒤 단원의 용어를 익힌다. |
| 2 | 물권법 | 50 | 물건을 둘러싼 권리관계와 당사자별 청구 구조를 정리한다. |
| 3 | 채권법 | 86 | 계약과 그 밖의 채권 발생원인, 이행·불이행·소멸을 연결한다. |
| 4 | 가족법 | 58 | 신분관계와 상속관계를 나누어 사례의 검토 순서를 익힌다. |

기존 학습순서 1~240을 기본으로 삼는다. `suggested_previous_unit`은 앞 단원을 찾는 안내값이며, 엄격한 선수학습 조건이 아니다. 이미 아는 단원은 실제 회상으로 확인하고 필요한 부분만 보완한다. 단원ID는 바꾸지 않는다.

## 하루 운영

오늘의 대상은 원본 `개념_오늘학습`에서 읽는다. 기본 설정은 신규 2단원·복습 3단원이지만, 이 저장소의 숫자로 원본 설정을 덮어쓰지 않는다. 처음에는 사용 가능한 학습시간 안에서 기존 추천 대상을 진행한다. 한 단원이 길면 같은 단원ID 안에서 수업을 나누고, 부분 학습을 전체 완료로 기록하지 않는다.

1. 기한이 도래한 회상과 신규 단원을 확인한다.
2. 해당 단원의 강의 파일만 읽어 핵심 구조를 설명한다.
3. 강의 화면을 닫고 별도 회상 파일로 질문한다. 답변 전 교정 근거를 읽지 않는다.
4. 실제 원답을 평가한다. 설명을 들었다는 사실은 독서 완료나 기억 성공의 근거가 아니다.
5. 공식 문제를 원하면 해당 브리지의 기존 절차로 출제한다. 연결표로 후보 순서를 바꾸지 않는다.
6. 원답·평가와 공식 성적을 각 원본에 구분해 기록한다. 복습 간격은 기존 수식의 1·3·7·21·60일 규칙을 따른다.

신규 2단원씩이면 240단원은 산술상 120학습일이다. 복습·문제풀이·휴일·부분 학습을 제외한 수치이므로 완료 예정일로 사용하지 않는다. 첫 주의 실제 학습시간과 회상 결과를 보고 주간 분량을 조절한다.

## 논점 우선순위

학습 순서는 다음 근거를 구분해 판단한다. 근거 없는 출제빈도·빈출 등급은 만들지 않는다.

- 선행 필요성: 뒤 단원의 용어를 이해하는 데 필요한 개념인지 확인한다.
- 공식 문제 연결: 기존 연결표에 등록된 사실과 그 검증 상태를 함께 확인한다.
- 공통 활용: 1차의 법리 구별과 2차의 사례 설명에 어떻게 쓰이는지 수업에서 확인한다.
- 개인 취약점: 해당 세션에서 원본 이력을 필요한 범위만 읽는다. GitHub에는 개인 이력을 옮기지 않는다.
- 구조적 중요성: 여러 단원의 권리관계를 설명하는 개념인지 판단하고, 판단 이유를 밝힌다.

## 시범 범위

첫 5단원은 실제 등록 ID와 원문 위치를 확보해 시범 강의를 작성했다. 선정과 제작은 학습 완료 판정이 아니다.

| 단원ID | 제목 | 단기 민법 PDF |
| --- | --- | --- |
| B1-P0008-0011 | 민법의 의의 | 1권 8~11쪽 |
| B1-P0012-0018 | 민법의 법원 | 1권 12~18쪽 |
| B1-P0019-0023 | 민법의 기본원리 | 1권 19~23쪽 |
| B1-P0024-0027 | 민법의 해석 및 효력범위 | 1권 24~27쪽 |
| B1-P0028-0035 | 법률관계와 권리·의무 | 1권 28~35쪽 |

나머지 단원은 색인과 수업 목표까지 준비했다. `core_topics`는 기존 목차·구간명이며, 각 구간의 세부 법리를 전수 검증했다는 뜻이 아니다. 상세 강의가 없는 단원은 그 범위의 원문을 확인한 뒤 수업을 준비한다.

색인의 `recall_question_ids`는 원본 개념 질문큐에 있는 기존 질문ID다. `recall_path`의 시범 질문은 별도로 작성한 연습 질문이므로 두 목록을 같은 문항으로 간주하지 않는다.

## 보충교재 사용

단기 민법의 순서와 단원ID를 유지한다. 보충교재는 같은 주제를 다른 설명으로 확인할 때만 좁게 읽는다. 두 교재의 편제 순서는 다르므로 장 번호로 연결하지 않는다. 대응 상태는 `sources/textbook-mapping.csv`에서 확인한다. 차이가 발견되면 자료별 설명을 구분하고, 현행 법령·판례를 확인하기 전 합성하거나 공식 정답을 바꾸지 않는다.
