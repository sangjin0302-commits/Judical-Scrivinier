# B1-P0012-0018 · 민법의 법원

강의 v4.0 · 검토 기준일 2026-10-27 · 학습용 일반 설명.

## 1층: 최초 핵심 수업

사람들이 늘 그렇게 거래했다는 말이 나오면 그 관행이 법인지, 합의를 해석할 자료인지 구별해야 한다. 법원(法源)은 재판기관이 아니라 적용할 법을 찾는 근거다.

A 3개를 `성문법·합의 확인 → 관행의 성격 → 적용 효과`로 묶는다. 반복 사실·법적 확신·전체 법질서와의 적합성, 강행·임의규정의 구별은 생략하지 않는다.

### 최소 구조와 필수 법리

1. 제1조는 민사에 관한 법률, 관습법, 조리의 순서로 규칙을 찾게 한다. 법률은 여기서 성문법을 넓게 가리킨다. 마음에 들지 않는 규정을 건너뛰어 조리부터 적용하지 않는다.
2. 관습법에는 반복된 관행 외에 법적 확신·인식이 필요하다. 전체 법질서에 비추어 정당성과 합리성도 갖춰야 한다. 횟수가 많다는 사실만으로 법규범이 되지는 않는다.
3. 사실인 관습은 당사자의 불명확한 의사를 보충한다. 제106조의 요건을 살피고, 명확한 합의가 있다면 제105조와 규정의 강행·임의 성질부터 검토한다. 관행으로 강행규정을 피할 수는 없다.

### 짧은 완결 사례

최산과 송민기가 거래 비용의 부담자를 정하지 않았고, 정우영은 업계에서 판매자가 내는 관행이 있다고 말한다. 우선 두 당사자의 합의와 관련 성문규정을 확인한다. 이어 관행의 실제 존재·내용과 법적 성격을 살핀다. 반복 사실만 알려져 있고 법적 확신은 확인되지 않았다면 관습법이라고 확정할 수 없다. 다만 의사가 불명확하고 제106조의 조건을 충족한다면 사실인 관습으로 검토할 여지는 있다. 주어진 정보만으로 최산에게 지급의무가 있다고 단정하지 않는 것이 이 사례의 결론이다. 실제 업종의 관습을 확인한 사례는 아니다.

### 확인 질문과 진행

질문 하나: 오래 반복됐다는 사실만으로 정우영의 말을 관습법이라고 확정할 수 없는 이유는 무엇인가?

반복 사실과 법적 확신, 의사 보충의 역할을 구별하면 다음으로 진행한다. 어렵다면 '사람들이 이렇게 해 왔다'와 '법적으로 반드시 그래야 한다고 받아들인다'의 차이를 재설명한다. 공식 점수·지연 기억 성공으로 저장하지 않고, 백지복습은 별도 명시 요청 때만 기존 recall을 사용한다.

## 2층: 조건부 보충 수업

첫 설명에서는 이 층을 한꺼번에 읽어 주지 않는다. 1층의 A 요건을 빠뜨린 답변에는 해당 A를 다시 설명하고, 새로운 B 논점이 실제로 등장할 때 B를 보충한다. 설명 층과 A/B/C 등급은 서로 다르다.

### 해당 쟁점이 드러날 때 — B 논점 상세 보충

과거에 인정된 관습이면 영원히 유효하다고 생각하면 2002다1178을 보충한다. 종중 구성원의 자격을 성년 남자로 제한하던 관습의 효력을 전체 법질서에 비추어 부정한 판결이다. 구체적 적용 시점은 따로 검토하며 모든 과거 관계가 자동으로 바뀐다고 확대하지 않는다. 주장입증을 혼동하면 PDF 14쪽과 80다3231의 해당 부분만 다시 읽는다.

### 유예 범위를 확인할 때 — C 지정 없음

확인한 범위에서 별도로 유예할 논점을 지정하지 않았다. 요건·효과·예외를 줄여야 한다는 뜻은 아니며, 이미 이해한 정의의 반복 낭독을 줄이는 것은 수업 운영 방식이다. 새로운 사례에서 부족한 점이 확인되면 B의 해당 근거를 보충한다.


## 공통 — 정상 진행과 근거 확인

공식 문제 적용과 출처 확인은 오답이 없어도 수업 준비·정상 진행에 필요할 때 수행한다. 조건부 재강의만을 위한 절차가 아니다.

### 공식 문제 적용으로 넘어갈 때 — 1차 구별·2차 목차

1차에서는 반복된 관행과 관습법, 관습법과 사실인 관습의 효력·주장입증을 구별한다. 80다3231은 법적 확신과 효력을 구별하는 근거다. 관습법은 원칙적으로 법원이 직권 확정하지만 알 수 없다면 당사자의 주장·입증이 필요해질 수 있다. 2차는 `적용 성문법·합의 → 관행의 성립과 성격 → 규범 또는 의사해석으로서의 효력 → 결론`으로 정리한다.


### 근거를 확인할 때 — 출처와 미검증 범위

- 주교재: `단기민법_1권_0001-0050.md`, PDF 12~18쪽. PDF 14쪽 시각 대조.
- 법령: 민법 제1조·제105조·제106조, Korean-law MCP lawId `001706`, 반환 시행일 2026-03-17.
- 판례: [80다3231 공식 원문](https://www.law.go.kr/LSW/precInfoP.do?evtNo=80%EB%8B%A43231)(MCP ID `97725`), [2002다1178 공식 원문](https://www.law.go.kr/LSW/precInfoP.do?precSeq=193822)(MCP ID `193822`) 전문 확인. 법령과 판례의 설명을 구별하여 작성.
- 로앤 법리 미합성. 교재 18쪽의 예시 이율을 현행 적법 이율로 재사용하지 않음.
- 후속 변경 판례의 전수 추적은 미실시. 공식 문제의 정답 변경 근거로 사용하지 않는다.

A/B/C는 선수 관계와 현재 설명 필요성에 따른 교수 판단이다. 실제 출제빈도나 검증된 공식 문항 연결을 뜻하지 않는다. 원본 브리지의 정상 상태·후보 순서를 따르며 답안 제출 전 채점키를 읽지 않는다.


### 공식 연결을 확인할 때 — 표본 근거와 한계

1차 표본에서 사실인 관습의 역할, 관습법의 효력 판단 시점, 주장·증명과 법원 확정의 구별을 관찰했다. 이 단원과의 주제 관련성은 교육설계 추론이며 공식 단원 연결은 미확인이다. 자세한 표본·조회 범위·미확인 한계는 [시험 요구능력의 확인 근거](../docs/exam-demand-evidence.md), 논점별 A/B/C는 [논점 지도](../curriculum/issue-map.csv)를 따른다. 원문·정오를 이 강의에 복제하지 않았으며 출제빈도는 산정하지 않았다.
