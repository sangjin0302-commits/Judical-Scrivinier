# B1-P0024-0027 · 민법의 해석 및 효력범위

강의 v4.0 · 검토 기준일 2026-10-27 · 학습용 일반 설명.

## 1층: 최초 핵심 수업

조문을 찾았어도 그 말이 사건의 사실을 포함하는지 설명해야 한다. 사실을 규정의 요건에 연결하는 일을 포섭이라고 한다. 이 연결이 빠지면 조문을 많이 외워도 사례 답안을 쓰기 어렵다.

A 3개를 `규정의 뜻 → 사실과 연결 → 적용 시점`으로 묶는다. 준용·유추, 선의·악의, 추정·간주의 구별은 같은 구조 안에서 설명한다.

### 최소 구조와 필수 법리

1. 사실 확정, 법규의 의미 확인, 포섭, 결론을 나눈다. 문리해석은 문언, 반대해석은 다른 취급의 이유, 유추해석은 직접 규정이 없는 경우의 유사성과 취지를 확인한다. 조문에 없다는 이유만으로 반대 결론이 자동으로 나오지는 않는다.
2. 준용은 입법자가 다른 규정을 적용하도록 정한 방식이고 유추는 해석 방법이다. 확장·축소·물론해석의 이름을 늘리기 전에 어떤 문언과 취지로 범위를 정하는지 설명한다. 제98조처럼 법이 정의한 용어는 그 정의부터 확인한다.
3. 선의·악의는 해당 사정을 모르거나 아는지를 가리킨다. 추정은 반대 사실의 증명으로 뒤집힐 수 있고, 간주는 법이 정한 취급이다. 개정 전후 사건은 행위일·시행일·경과규정을 따로 확인한다.

### 짧은 완결 사례

최산과 송민기가 개정 전에 거래했고, 정우영은 재판이 개정 뒤에 열리니 새 조문만 쓰자고 한다. 당사자는 최산과 송민기이고 실제 청구의 요건은 적용될 법에 달려 있다. 그래서 거래일과 새 법 시행일을 적은 뒤 그 개정의 경과규정을 확인한다. 재판일 하나만으로 적용법을 확정할 수 없다는 것이 현재 정보로 내릴 결론이다. 확인되지 않은 경과규정을 만들어 결론을 완성하지 않는다.

같은 방식으로 '송민기는 착한 사람이니 선의다'라는 설명도 고친다. 법률상 선의가 문제라면 송민기가 무엇을 알았는지 확인해야 한다. 사람의 인품을 평가해서 규정의 요건을 대신할 수 없다.

### 확인 질문과 진행

질문 하나: 정우영이 재판일만으로 새 법을 적용하려 할 때 무엇을 먼저 확인해야 할까?

행위일·시행일·해당 경과규정을 구별하면 다음으로 진행한다. 어렵다면 사건의 시간 순서를 두 줄로 다시 설명하고 추가 질문을 늘리지 않는다. 즉시 이해는 채팅에서만 확인하고 백지복습은 별도 명시 요청 때만 기존 recall을 사용한다.

## 2층: 조건부 보충 수업

첫 설명에서는 이 층을 한꺼번에 읽어 주지 않는다. 1층의 A 요건을 빠뜨린 답변에는 해당 A를 다시 설명하고, 새로운 B 논점이 실제로 등장할 때 B를 보충한다. 설명 층과 A/B/C 등급은 서로 다르다.

### 해당 쟁점이 드러날 때 — B 논점 상세 보충

특정 개정이 나오면 그 경과규정, 외국적 요소가 나오면 필요한 국제사법 규정을 확인한다. 현재 세부 규정은 미검증이므로 구체적 결론을 말하지 않는다. 법리와 포섭을 혼동하면 앞 단원의 2001다53059에서 신뢰 형성 사실과 법리가 연결되는 부분을 다시 설명한다.

### 유예 범위를 확인할 때 — C 지정 없음

확인한 범위에서 별도로 유예할 논점을 지정하지 않았다. 요건·효과·예외를 줄여야 한다는 뜻은 아니며, 이미 이해한 정의의 반복 낭독을 줄이는 것은 수업 운영 방식이다. 새로운 사례에서 부족한 점이 확인되면 B의 해당 근거를 보충한다.


## 공통 — 정상 진행과 근거 확인

공식 문제 적용과 출처 확인은 오답이 없어도 수업 준비·정상 진행에 필요할 때 수행한다. 조건부 재강의만을 위한 절차가 아니다.

### 공식 문제 적용으로 넘어갈 때 — 1차 구별·2차 목차

1차는 준용·유추, 추정·간주, 법률상 선의·일상적 선의를 구별한다. 제184조의 '미리'는 시효완성 전후를 나누는 반대해석 예시지만 모든 문언에 같은 방식을 강제하지 않는다. 2차 목차는 `필요 사실 → 적용 법과 시점 → 문언·취지 → 포섭 → 결론`이다.


### 근거를 확인할 때 — 출처와 미검증 범위

- 주교재: `단기민법_1권_0001-0050.md`, PDF 24~27쪽. PDF 24쪽 시각 대조.
- 법령: 민법 제98조·제184조. Korean-law MCP lawId `001706`, 반환 시행일 2026-03-17.
- 적용 예시 판례: [2001다53059 공식 원문](https://www.law.go.kr/LSW/precInfoP.do?evtNo=2001%EB%8B%A453059&mode=0), MCP ID `194584` 전문 확인. 교재 20쪽에 실린 앞 단원 자료의 재사용임.
- 제정·개정 부칙과 국제사법 세부 규정은 미검증이므로 구체적 결론을 제시하지 않음. 로앤 법리 미합성.

A/B/C는 선수 관계와 현재 설명 필요성에 따른 교수 판단이다. 실제 출제빈도나 검증된 공식 문항 연결을 뜻하지 않는다. 원본 브리지의 정상 상태·후보 순서를 따르며 답안 제출 전 채점키를 읽지 않는다.


### 공식 연결을 확인할 때 — 표본 근거와 한계

2차 표본에서 같은 재산관계라도 사실의 법적 분류와 청구 주체를 구별해야 함을 관찰했다. 해석·포섭을 A로 유지한 것은 선수학습 설계이며 이 단원과의 직접 공식 연결은 미확인이다. 자세한 표본·조회 범위·미확인 한계는 [시험 요구능력의 확인 근거](../docs/exam-demand-evidence.md), 논점별 A/B/C는 [논점 지도](../curriculum/issue-map.csv)를 따른다. 원문·정오를 이 강의에 복제하지 않았으며 출제빈도는 산정하지 않았다.
