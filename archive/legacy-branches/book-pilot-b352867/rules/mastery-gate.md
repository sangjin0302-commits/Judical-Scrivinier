# 이해도에 따른 다음 학습 결정

이 규칙은 ChatGPT가 다음 논점과 보충량을 정하는 기준이다. 기존 시트의 공식 통과·졸업·복습일 판정을 대체하거나 수정하지 않는다. 수업 방식은 [교수법 정본](teaching-method.md), 필수 논점은 [압축 교육과정](compression-curriculum.md)을 따른다.

## 서로 다른 다섯 증거

| 영역 | 확인할 실제 행동 | 이 증거만으로 인정할 수 없는 것 |
|---|---|---|
| 직후 개념 이해 | 새 사례의 당사자·권리의무·핵심 요건을 자기 말로 설명 | 장기 기억·공식 문제 실력 |
| 책을 덮고 설명 | 자료·힌트 없이 요건→효과와 중요한 예외를 설명 | 날짜를 달리한 기억 유지 |
| 1차 OX 적용 | 정상 브리지로 선정한 실제 문항에 응답하고 공식 채점 결과 확인 | 사례형 쟁점·포섭 능력, 민법 전체 숙련 |
| 2차 사례 적용 | 실제 사례에서 쟁점·법리·구체적 사실의 포섭을 작성하고 기존 7요소 평가 확인 | 장기 기억, 한 사례 밖의 모든 유형 숙련 |
| 지연 기억 | 기존 복습 일정의 다른 날에 설명·힌트 전 실제 응답 | 새 문제 유형으로의 전이 전체 |

각 영역을 `미확인 / 보충 필요 / 해당 범위 확인`으로 세션에서 구분하고 근거가 된 실제 답변 범위·힌트 제공 여부를 남긴다. 이 문구는 새 원본 시트 열이나 공식 점수로 쓰지 않는다. 가상 답변·강의 제공·단순한 “알겠어”만으로 모든 영역을 확인 처리하지 않는다.

## 진행과 보충

직후 1~2개 확인에서 현재 A의 핵심 관계·요건을 잘못 이해하지 않고 사례에 적용할 수 있으면 공식 문제나 다음 논점으로 잠정 진행한다. 모든 지연 복습이 끝날 때까지 신규 진도를 막지 않는다. 확인하지 않은 A 논점과 1차·2차·지연 기억 영역은 미확인으로 남긴다. 일부 답변을 단원 전체 완료로 확대하지 않는다.

핵심 원칙·요건·중요 예외가 틀리면 그 부분만 다른 사례로 재강의한다. 설명 후 확인은 교수법 정본의 제한을 지킨다. 계속 어렵다면 질문 수를 늘리지 않고 선수개념으로 범위를 줄인다. 이미 이해한 나머지 부분까지 처음부터 반복하지 않는다.

OX는 맞았지만 이유의 조건을 혼동하면 그 구별을 보충한다. 사례에서 법리를 외웠어도 포섭이 빠지면 사실과 요건을 연결하는 시범을 추가한다. 어느 한 차수의 결과가 없으면 해당 능력을 미확인으로 남기고, 이후 별도 세션에서 검증한다. 매일 두 차수의 모든 검사를 끝내야 다음 진도로 갈 수 있게 하지 않는다.

지연 회상에서 실패하면 기존 복습 규칙으로 처리하고 필요한 A/B 설명을 보완한다. 학습 지도를 고칠 때도 과거 답안·점수·평가를 삭제하거나 새 결과로 덮어쓰지 않는다. 기존 공식 판정과 이 학습 판단이 다르면 두 상태를 함께 설명한다.

## 단원별 목표의 범위

각 강의는 무엇을 설명·구별·적용할 수 있어야 하는지 구체적으로 적는다. 기준은 공식 합격선이나 검증된 예측모형이 아니라 보충 수업을 정하기 위한 관찰 항목이다. 단 한 번의 정답률로 합격 가능성을 추정하지 않는다. 실제 시간·정확성·누락 논점의 비교는 [시범운영 계획](../docs/compression-pilot-plan.md)을 따른다.
