# 빠른 조회

2026-10-27 현행 코드 확인 결과, PB1 통합 출제·채점은 후보 조건과 기록 안전 계약이 맞지 않아 실행을 보류한다. 기존 범위별 브리지 절차를 따른다. 운영 원본에 `PB1_testEndToEnd`를 실행하지 않는다. 근거와 재개 조건은 [현행 계약 점검](../docs/pb1-current-contract.md)에 있다.

- START와 [교수법 정본](teaching-method.md), 해당 작업 규칙, 현재 단원의 강의만 읽는다. 짧은 회상에 쓸 질문만 추가로 고르며 질문 파일 전체를 순서대로 소비하지 않는다.
- 단원ID를 알면 파일을 직접 조회한다. 매번 전체 저장소 검색을 하지 않는다.
- 압축 교육과정·이해도 판단 규칙은 세션 최초 또는 버전 변경 시 읽는다. 논점 지도는 현재 단원 행을 우선 사용하고 문제 원문은 연결 근거가 새로 필요하거나 자료가 갱신된 경우에만 다시 확인한다. 공식 채점키는 미리 읽지 않는다.
- 독립 읽기는 묶는다. 설정 변경 → 재계산 결과 확인 → 후보 선택 → 문제 확인은 의존 순서를 유지한다.
- 시트는 A1 주소로 필요한 범위만 읽는다. 문제별 왕복 대신 세트 단위로 읽고 기록한다.
- 자료 버전이 같으면 정적 설명을 재사용한다. 브리지 상태·선택키·기록행은 쓰기 직전 확인한다.
- 같은 세션에서 읽은 강의·법리 근거는 유지한다. 이해 확인 답변마다 강의 전체·오늘학습 전체를 다시 조회하지 않는다. 새 단원·자료 개정·근거 누락·기록 직전 상태 변화가 있을 때만 필요한 범위를 갱신한다.
- 오늘학습의 복습·신규 추천은 가능한 한 한 번의 좁은 조회로 읽는다. 같은 단원 정적 정보는 ID·버전으로 재사용한다. 조회 실패를 이유로 문제를 연속 출제하지 않는다.
- 자료 조회 최적화는 설명을 생략하는 것이 아니다. 이해가 안 되면 확보한 근거로 사례·표현을 바꿔 가르치고, 새 법리가 필요한 경우에만 추가 출처를 확인한다.
- 같은 lessons의 1층 구조를 먼저 설명하고, 확인된 조건에 해당하는 2층만 펼친다. 같은 A에 연결된 정의·요건·사례를 한 설명으로 묶어 반복을 줄이되 필수 예외를 숨기지 않는다. 이미 확보한 강의의 다음 절을 사용하려고 전체 파일을 재조회하지 않는다.
- PDF 전체 반복 조회를 피하고 색인→해당 Markdown→필요 PDF 페이지 순서로 읽는다.
- 채점키 사전 조회·상태 검사 생략·후보 재선정·원답 생략을 속도 개선으로 취급하지 않는다.

시간은 외부 호출 전체 왕복시간, 시트 계산시간, ChatGPT 생성시간을 구분한다. 분리 관측이 안 되면 전체 왕복시간만 보고한다. 상세 수치는 docs/performance-baseline.md에 둔다.
