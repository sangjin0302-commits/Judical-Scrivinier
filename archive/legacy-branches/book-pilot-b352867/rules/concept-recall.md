# 교수 단계와 평가·기록 단계

수업 방식은 [교수법 정본](teaching-method.md)을 따른다. 이 파일은 평가와 기록의 경계를 정한다. 교수 단계에서는 lessons와 교재 근거를 읽어 먼저 설명한다. 회상 질문을 낸 뒤에는 강의의 해당 답을 함께 보여주지 않고 실제 응답을 기다린다. 이전에 가르친 내용을 지우거나 모른다고 가장할 필요는 없다. 답변 전 교정 근거를 새로 조회해 힌트를 붙이지 않는다.

| 활동 | 해석 | 기록 |
|---|---|---|
| AI 강의·사례 설명 | 설명을 제공한 사실 | 채팅에 다룬 범위·남은 논점만 정리. 독서 완료·기억 성공 기록 금지 |
| 강의 직후 이해 확인 | 설명 직후의 이해·적용 확인 | 실제 원답과 교정을 채팅에 구분. 지연 회상 성공으로 저장하지 않음 |
| 날짜를 둔 백지복습 | 설명·힌트 전 실제 원답에 근거한 회상 | 확인된 기존 활동구분·기록 계약에 따라 개념_회상이력에 추가 |
| 공식 OX·사례 | 기존 브리지로 출제한 실제 답안의 공식 평가 | 해당 차수의 공식 기록 규칙 적용 |

즉시 이해 확인을 저장할 별도 활동구분과 수식 영향이 확인되지 않았으므로 현재는 채팅에서 운영한다. 기록을 위해 임의 유형·날짜·성공횟수를 만들지 않는다. 설명을 받은 뒤 같은 질문에 답한 것을 독립 백지회상으로 바꾸지 않는다. 도입 복습도 실제 응답과 활동 조건이 충족된 범위만 기록한다.

기존 recall 파일·질문큐에 질문이 많아도 기본 수업에서 전부 출제하지 않는다. 질문 수와 재강의 전환은 교수법 정본을 따른다. 사용자가 백지복습만 명시적으로 요청하면 그 요청 범위에서 진행한다.

지연 회상의 실제 답변을 받은 뒤 확인된 근거를 필요한 범위만 대조한다. 핵심 요건·효과·예외·판례 결론이 맞으면 기억함, 큰 틀은 맞지만 중요한 누락이 있으면 부분 기억, 핵심 오류나 회상 실패이면 재복습으로 평가한다. 강의를 제공하거나 사용자가 답변하지 않은 것만으로 평가하지 않는다. 미확인 법리로 단정 채점하지 않는다.

## 기록

개념_회상이력 다음 빈 행 A:L:

실제 기록일 / 단원ID / 회상세트ID / 활동구분 / 실제 회상 원답 / 회상평가 / 누락·교정 / 학습시간(분) / 원답 확인 / 확인한 기본서 출처 / 확인된 공식 문제 안정키 / 비고.

사용자의 실제 원답을 보존하고 교정문으로 대체하지 않는다. 측정하지 않은 학습시간과 미확인 연결키는 비워둔다. 일부 질문만 답했다면 실제 범위를 비고에 남기고 단원 전체 완성으로 확대하지 않는다.

독서는 사용자가 실제 읽었다고 확인한 때만 기록한다. 강의 청취를 임의로 독서 활동으로 바꾸지 않는다. 새로운 활동구분이 필요하면 원본 스키마 변경 제안으로 남긴다.

복습 간격은 재복습 1일, 부분 기억 3일, 기억함 1회 7일, 서로 다른 날 연속 2회 21일, 연속 3회 60일이다. 기존 설정과 수식이 계산하며 직접 날짜·성공횟수·통과를 쓰지 않는다.

문제은행 유래 백지복습은 공식 OX/서술형 점수와 별도다. 백지복습이력 탭이 있어도 현재 적용 스키마·기록 근거를 확인하지 못하면 채팅에서만 운영한다.
