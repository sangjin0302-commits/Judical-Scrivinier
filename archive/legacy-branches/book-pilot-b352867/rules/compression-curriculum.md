# 시험 요구에서 설계하는 압축 교육과정 — 정본

버전 1.0 / 2026-10-27. 목적은 필요한 법리 이해와 1차·2차 문제 해결능력을 유지하면서 총 학습시간을 줄이는 것이다. 페이지 수·강의 수·질문 수 감소를 성과로 보지 않으며 합격을 보장하지 않는다. 무엇을 배울지는 이 규칙, 어떻게 가르칠지는 [교수법 정본](teaching-method.md), 다음 논점으로 갈지는 [이해도 판단 규칙](mastery-gate.md)을 따른다.

## 문제 요구 → 법리 → 교재 → 강의

1. 기존 공식 문제와 갱신된 Google Docs에서 필요한 지문·메타데이터만 확인한다. 1차의 판단 조건·예외·개념 구별, 2차의 청구·쟁점·요건·포섭 요구를 추출한다. 이번 유지보수 분석은 답을 맞히는 작업이 아니며 정답키·모범답안·개인 답안을 읽지 않는다.
2. 안정키와 원본 위치를 확인하고 요구능력을 독립적으로 요약한다. 실제 지문 확인, 메타데이터만 확인, 연결 후보, 미확인을 구별한다. 문제 지문과 해설은 GitHub에 복제하지 않는다. 기존 개념_문제연계는 확인된 범위만 재사용하며 후보 연결을 확정 연결로 승격하지 않는다.
3. 주교재 단기 민법의 해당 페이지와 맞춰 필수 논점·요건·효과·예외를 확인한다. 문제은행에 없더라도 다른 법리를 이해하는 데 필요한 선수개념이나 법적 판단에 필수적인 요건은 빠뜨리지 않는다.
4. 논점별 A/B/C와 이유를 [논점 지도](../curriculum/issue-map.csv)에 기록한다. 실제 문제 요구에 근거한 부분과 선수학습에 관한 교육설계 판단을 분리한다. 로앤은 해당 논점·위치를 실제 확인했을 때만 보충 근거로 쓴다.
5. A를 먼저 가르치고 문제 적용에서 B·C가 필요해지면 승격한다. 실제 학습 결과에 따라 분량을 조절하되 공식 출제 후보 순서·통과 수식은 바꾸지 않는다.

새 자료가 갱신되면 변경된 문제의 안정키·판단요소와 연결 논점만 재검토한다. 기존 선지를 매 수업 법리 재검증하지 않는다. 자료 충돌·개정 징후·이상한 채점 결과가 있을 때 필요한 법령·판례만 확인하고 공식 정답을 임의 수정하지 않는다.

지문 분석은 답이 분리된 문제원장 G열과 필요한 메타데이터를 우선한다. Google Docs는 정답·해설과 분리된 지문 범위가 확인된 때만 읽는다. 제목이나 주변 문단에 정오 표시가 결합되어 있으면 추가 조회를 중단하고 Docs 대조 미완료로 남긴다. 키 문자열의 위치를 찾았다는 사실만으로 주변 범위를 안전한 지문이라고 가정하지 않는다. 이번 확인의 제한은 [시험 요구 근거](../docs/exam-demand-evidence.md)에 기록했다.

## A/B/C 분류

| 구분 | 선정 근거 | 수업 처리 | 미룰 수 없는 조건 |
|---|---|---|---|
| A 필수 핵심 | 확인된 문제의 판단에 필요한 법리 또는 교재·현행 근거로 확인한 필수 선수개념·요건·효과·중요 예외 | AI가 이유와 사례를 직접 설명하고 짧게 이해 확인 | 판단을 바꾸는 요건·예외를 단순히 분량 때문에 제외하지 않음 |
| B 적용·오답 보완 | A만으로 원칙을 이해할 수 있으나 특정 사실관계·쟁점·혼동을 풀 때 추가 설명이 필요한 법리 | 기본 구조는 짚고 해당 문제·오답·불이해가 생길 때 상세 설명 | 현재 문제의 결론·포섭에 필요하면 즉시 상세 학습 |
| C 필요시 참고 | 확인한 교재에서 중복 설명·배경·심화에 해당하고 현재 A의 이해와 판단에 필수적이지 않다고 설명할 수 있는 부분 | 최초 상세 정독을 유예하고 정확한 범위·이유·복귀 조건을 남김 | 새 문제·선행 필요·누락 검토에서 필요성이 확인되면 B 또는 A로 승격 |

C는 시험에 나오지 않는다는 뜻이 아니다. 교재의 논점을 확인하지 못했으면 C로 넣지 않고 미분류로 남긴다. 빈출 통계가 없으면 빈출·고빈도·출제확률을 쓰지 않는다. 모든 단원에 A/B/C를 같은 개수로 배정하지 않는다. 단원 전체가 아니라 논점별로 구분하며 같은 단원 안에서도 수업 분량이 달라진다.

## 누락 방지와 승격

각 시범 단원의 확인한 교재 범위를 논점 지도와 대조해 A, B, C 또는 미분류로 설명한다. 논점 지도는 모든 조문·판례를 전수 검증했다는 인증서가 아니다. 범위 밖의 내용·원문 접근 실패·PDF 미대조·연결 미검증을 명시한다. 해설을 읽지 않은 문제 요구 분석을 정답 검증이라고 부르지 않는다.

공식 문제에서 실패하면 먼저 지식 부족, 조건 구별 실패, 사실관계 적용 실패, 기억 문제를 나눈다. 빠진 필수 법리이면 A에 추가하고 기존 관련 강의에 반영한다. 적용 사례가 부족하면 B 설명을 보강한다. 이미 아는 내용을 길게 반복하지 않는다. C 승격 사유와 확인일은 자료 변경 기록에 남기되 개인 원답을 공개 저장소에 옮기지 않는다.

## 진도·시간·기록

240개 원본 단원ID는 참조 체계로 유지한다. 페이지 수나 단원 수로 같은 시간을 배분하지 않는다. 새 논점은 선수관계와 실제 학습상태에 따라 고르며 복습 대기열 전체 완료를 신규 강의의 조건으로 삼지 않는다. 일일 흐름과 질문 제한은 교수법 정본을 따른다.

AI 강의로 설명받은 범위와 사용자가 직접 읽은 범위는 구분한다. 기존 시트에 없는 활동유형은 만들지 않고 채팅에만 남긴다. 실제 독서는 사용자 확인 후 기존 계약으로, 지연 회상은 실제 원답 후 기존 회상이력으로, 공식 점수는 해당 브리지 규칙으로 기록한다. 기존 복습 간격 1·3·7·21·60일과 자동수식·이력은 유지한다. PB1은 사용하지 않는다.

효율 평가는 AI 설명 시간만이 아니라 이해 확인·문제풀이·재강의·보충 독서·지연 복습에 든 시간을 함께 비교한다. 동일 학습 범위의 이해·OX·사례 적용·지연 기억이 나빠지면 짧아진 시간을 성공으로 보고하지 않는다. [시범운영 계획](../docs/compression-pilot-plan.md)에 따라 실제 데이터를 모으기 전에는 절감률을 제시하지 않는다.

## 현재 적용 범위

우선 기존 강의가 있는 7단원의 논점을 분류·개편한다. 나머지 233단원은 미분류·상세 강의 미제작이며, 실제 진도에 맞춰 문제 요구와 교재를 대조한 뒤 추가한다. 출처가 없는 A/B/C 값을 일괄 생성하지 않는다. 현재 지도는 시범 범위의 설계이며 민법 전체 시험범위를 완전히 포괄한다고 주장하지 않는다.
