# B1-P0040-0047 · 신의성실·권리남용 회상

질문 전용 v1.0. 답변 전에는 강의·교정 근거·판례 결론을 조회하거나 공개하지 않는다. 질문을 하나씩 제시한다. 공식 문제은행·기존 질문큐와 구별되는 독립 개념 연습이다.

1. 신의칙을 적용할 때 어떤 사실을 확인하며, 구체적 법규와는 어떤 순서로 검토하는가?
2. 선행행위와 후행행위가 모순된다는 주장만으로 충분한가? 추가 판단 요소를 설명하라.
3. 최산과 송민기의 장기 계약에서 정우영이 손해 발생을 보고했다. 사정변경 여부를 판단하려면 어떤 정보를 더 물어야 하는가?
4. 신의칙과 제한능력자 보호 규정이 문제 될 때 주의할 점을 설명하라.
5. 법원의 직권 판단 가능성과 사실에 관한 증거 필요성은 어떻게 구별되는가?

제출 후 처리: 같은 ID의 강의에서 필요한 근거만 읽고 실제 답변을 기억함·부분 기억·재복습으로 평가한다. 미제출 답변을 만들거나 공식 점수로 바꾸지 않는다. 기록은 `rules/concept-recall.md`를 따른다.
