# B1-P0012-0018 · 민법의 법원 회상

질문 전용 v1.0. 답변 전에는 강의·교정 근거·판례 결론을 조회하거나 공개하지 않는다. 질문을 하나씩 제시한다. 공식 문제은행 문항이 아닌 개념 연습이다.

1. 민법 제1조에 따라 적용할 규칙을 찾는 순서를 설명하라.
2. 오랫동안 반복된 관행이 관습법인지 판단하려면 무엇을 더 확인해야 하는가?
3. 관습법과 사실인 관습의 성격·효력·주장입증 문제를 구별하라.
4. 최산과 송민기가 거래 조건을 명확히 정하지 않았고 정우영이 업계 관행을 주장한다. 적용 근거를 찾기 위해 무엇부터 확인할 것인가?
5. 이미 관습법으로 인정된 규범도 효력이 달라질 수 있는가? 판단 기준을 설명하라.

제출 후 처리: 같은 ID의 강의에서 필요한 근거만 읽는다. 실제 답변의 오류와 누락을 구분해 기억함·부분 기억·재복습으로 평가한다. 미제출 답변을 만들거나 공식 점수로 바꾸지 않는다. 기록은 `rules/concept-recall.md`를 따른다.
