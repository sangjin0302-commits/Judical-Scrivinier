# B1-P0072-0079 · 자연인 구간 2 회상

질문 전용 v1.0. 답변 전에는 강의·교정 근거·판례 결론을 조회하거나 공개하지 않는다. 질문을 하나씩 제시한다. 공식 문제은행·기존 질문큐와 구별되는 독립 개념 연습이다.

1. 미성년자의 거래를 검토할 때 동의의 원칙과 예외를 어떤 순서로 확인하는가?
2. 최산이 송민기에게서 할인된 물건을 샀고 정우영은 최산의 법정대리인이다. 계약 효력을 판단하기 위해 필요한 사실을 물어보라.
3. 성년후견·한정후견·특정후견의 차이를 행위능력 중심으로 설명하라.
4. 상대방의 확답 촉구에서 대상·기간·응답이 없을 때의 효과를 설명하라.
5. 철회권과 거절권의 대상·행사 시기·상대방의 인식 요건을 비교하라.
6. 법정대리인의 동의 없는 본인의 행위와 친권자의 대리권 남용은 어떤 점이 다른 문제인가?

제출 후 처리: 같은 ID의 강의에서 필요한 근거만 읽고 실제 답변을 기억함·부분 기억·재복습으로 평가한다. 미제출 답변을 만들거나 공식 점수로 바꾸지 않는다. 기록은 `rules/concept-recall.md`를 따른다.
