# book-to-skill 민법 압축 과외 도입 실험

검토일 2026-10-28 · 시범 단원 `B1-P0040-0047` · 운영 Google 자산 변경 없음

## 결론

전체 도구를 복제하거나 생성 명세를 그대로 적용하지 않는다. 공식 `book-to-skill`의 **페이지 추출, 입력 해시, 변경 감지, 장별 온디맨드 조회, 보안 정제** 개념만 최소 어댑터로 재사용할 가치가 있다. 민법의 법리 선정·강의 구조·완료 판정은 기존 정본이 더 엄격하고 이미 구현돼 있으므로 기존 규칙을 유지한다.

시범 강의는 A 논점 4개와 B 논점 1개를 모두 보존했고, 필수 체크리스트 기준 누락은 0건이다. 다만 이는 단원 지도와 확인 범위에 대한 누락 검사이지 민법 전체 또는 모든 판례의 전수 검증이 아니다. 기존 강의보다 파일 조회량은 줄었지만 로컬 파일 읽기 차이는 0.01ms 미만이라 사용자 체감 개선 근거가 되지 않는다. ChatGPT 전체 응답시간은 이 환경에서 분리 계측하지 못했으므로 개선을 주장하지 않는다.

## 1. 공식 프로젝트 검토

- 공식 저장소: `virgiliojr94/book-to-skill`, 커밋 `fece258123879acf4ac6535dc4986b32e13df0c9`(2026-10-27), 최신 태그 `v1.4.0`.
- 라이선스: 변환기 코드는 MIT. 처리 대상 기본서의 저작권에는 적용되지 않는다.
- 구조: Python 결정론적 추출기가 `full_text.txt`와 `metadata.json`을 만들고, 에이전트가 `SKILL.md` 명세에 따라 장 파일·용어집·패턴·치트시트를 생성한다.
- 기본 런타임은 Python 3.9 이상이며 핵심 패키지는 필수 의존성이 없다. 선택 의존성은 PDF(`pdf-inspector`, `pypdf`, `pdfminer.six`, 기술문서용 `docling`), EPUB, DOCX, HTML, RTF, Calibre 등이다. 버전 범위가 느슨한 선택 패키지가 많고 lock 파일이 없으므로 전부 설치하는 방식은 공급망·재현성 비용이 크다.
- 보안상 장점: 경로를 절대화해 subprocess 인자 주입을 완화하고, 보이지 않는 Unicode를 제거하며, DOCX의 DTD/entity를 거부하고, 작업 디렉터리 소유권·심볼릭 링크를 검사한다. 생성 결과에 대한 프롬프트 주입 탐지기도 있다.
- 주의점: `--install-missing yes`는 현재 Python으로 `pip install`을 실행한다. 이번 실험에서는 사용하지 않았다. PDF·EPUB 같은 비신뢰 입력은 결국 외부 파서의 공격면을 가진다. 공식 저장소라고 해도 선택 의존성은 별도 검토·고정이 필요하다.
- 공식 보안 공지상 유사 이름의 비공식 재업로드에 악성 정보탈취 코드가 발견됐다. 공식 URL과 커밋을 고정해야 한다.

| 공식 문제 연결·채점 | 범위 밖 | 기존 브리지의 후보 순서·채점·기록을 대체하지 않는다. |

## 5. 비용과 성능

- 비공개 범위 캐시 생성: 20회, 실패 0회, 최소 151.894ms / 중앙 312.426ms / 최대 950.396ms. 139,406-byte Markdown에서 40~47쪽 14,620자를 추출하고 해시·메타데이터를 기록하는 전체 프로세스 실행시간이다.
- 로컬 강의 조회 100회: 기존 최소 0.145ms / 중앙 0.166ms / 최대 0.647ms, 시범 최소 0.144ms / 중앙 0.158ms / 최대 0.777ms, 각 실패 0회.
- 조회량은 14,547 bytes에서 5,547 bytes로 61.9% 감소했다. 이는 파일 바이트 감소일 뿐 토큰 절감률·응답시간 감소율·학습시간 감소율이 아니다.
- 법리 검증은 5개 논점과 교재 8쪽, 법령 1개 조문, 핵심 판례 기준을 사람이 확인해야 했다. 이 판단 비용은 자동 추출로 제거되지 않는다.
- ChatGPT 종단 응답 대기시간, 이해 확인 시간, 공식 문제 적용 시간은 이번 로컬 도구로 분리 계측할 수 없어 미측정이다.

## 6. 최소 코드 범위

- `tools/civil_book_pilot.py`: 페이지 경계 추출, 숨은 Unicode 제거, SHA-256 변경 감지, 비공개 캐시와 원문 없는 공개 색인 분리.
- `tools/benchmark_civil_book_pilot.py`: 기존·시범 강의의 로컬 조회량과 읽기시간 측정.
- `tests/test_civil_book_pilot.py`: 연속 페이지 경계, 범위 밖 배제, 숨은 문자 제거, A/A/A/A/B 보존 검사.
- upstream 전체 코드, 생성용 `SKILL.md`, 선택 의존성은 vendoring하지 않았다. upstream 코드를 복사하지 않았으므로 MIT 코드 고지를 추가할 실질 코드 사본도 없다.

## 7. 확대 적합성

민법 확대는 **조건부 적합**이다. 다음 2~3개 단원에서 필수 논점 누락 0, 출처 페이지 연속성, 조건부 보충 복귀, 실제 수업 응답시간과 문제 적용 품질을 다시 측정해야 한다. 기존 강의가 이미 충분히 작고 정확한 단원에서는 새 변환이 이득이 없다.

타 과목 확대는 곧바로 권하지 않는다. 법령·판례 중심 과목은 과목별 정본·단원 ID·현행성 검증기가 먼저 필요하고, 등기·집행처럼 절차·서식·선후관계가 중요한 과목은 일반 장 요약이 위험하다. 기술적 추출·해시·온디맨드 조회 틀만 공통화하고 법리 스키마는 과목별로 검증해야 한다.

## 안전 경계

기본서 PDF·전체 추출문·저작권 보호 표현, 공식 문제 정답키, 개인 답안·이력은 커밋하지 않았다. 공개 파일에는 독립 작성 설명과 좁은 출처 메타데이터만 포함한다. 운영 Google Sheets·Docs·Apps Script를 읽거나 변경하지 않았고 기존 PR #1·#2와 1차 채점 속도 작업도 변경하지 않았다.
