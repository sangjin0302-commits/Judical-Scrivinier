# 합격 대비 압축 교육과정 시범 결과

확인일 2026-10-27. 기존 교수법 개편을 유지하면서 시험에 필요한 법리 선정과 총 학습시간 검증을 상위 목표로 삼았다. 이번 결과는 교육과정과 수업자료의 준비이며 실제 학습효과나 합격 가능성을 검증한 결과가 아니다.

## 준비한 범위

기존 7개 강의를 모두 검토·개편하고 논점 지도에 32개 논점을 넣었다. A 24개는 직접 가르칠 핵심, B 7개는 특정 적용·오답 때 상세 보충할 법리, C 1개는 조건부로 상세 학습을 미룰 배경 논점이다. C는 기본원리 PDF 19쪽의 최고원리에 관한 학설 대립이다. 이를 시험에 불필요하다고 확정하지 않았으며, 학설 비교를 묻거나 원칙 이해에 필요해지면 승격한다.

기존 240개 단원ID는 모두 유지했다. 지도에는 나머지 233단원을 미분류로 표시했다. 모든 단원을 같은 비중으로 가르치거나 미분류를 생략 대상으로 취급하지 않는다. 상세 교육과정 전체가 완성됐다고 주장하지 않는다.

## 기존 7강의 두 층 구성 검토

별도 요약 파일을 만들지 않고 각 강의를 `1층: 최초 핵심 수업`과 `2층: 조건부 보충 수업`으로 재구성했다. 1층은 구조·모든 A의 최소 법리와 예외·짧은 완결 사례·확인 질문을 담는다. 2층은 해당 어려움이나 실제 쟁점이 나타날 때 열 상세 설명·판례다. 정상 공식 문제 진행과 출처 확인은 별도 공통 절에 두어 오답이 없어도 사용할 수 있게 했다. A를 다시 설명한다고 등급 B가 되는 것은 아니며 A 24/B 7/C 1의 분류를 바꾸지 않았다.

| 단원 | 묶어서 먼저 설명할 A | 1층에 반드시 유지할 구별·예외 | 2층을 여는 구체적 조건 | C 검토 |
|---|---|---|---|---|
| 민법의 의의 | 법의 범위 → 권리·의무 → 실현 절차 | 국가의 사법관계 가능성, 특별규정, 계약과 소유권 이전의 구별 | 국가 계약의 추가 사실이나 물권변동·절차 쟁점이 등장 | 별도 C 없음 |
| 민법의 법원 | 성문법·합의 → 관행의 성격 → 효과 | 법적 확신·정당성, 사실인 관습, 강행규정의 한계 | 관습법 변화의 시점·판례 범위·주장입증을 혼동 | 별도 C 없음 |
| 민법의 기본원리 | 자유 → 한계 → 책임 요건 | 사회질서 위반, 소유권의 범위, 책임 요건, 신뢰손해 | 비용의 범위가 불명확하거나 특별책임 규정이 필요 | 최고원리 학설 대립만 유예; 직접 요구·이해 필요 시 B 승격 |
| 민법의 해석 및 효력범위 | 규정의 뜻 → 사실 연결 → 적용 시점 | 준용·유추, 선의·악의, 추정·간주, 경과규정 확인 | 실제 개정·외국적 요소·해석상 오해가 등장 | 별도 C 없음 |
| 법률관계와 권리·의무 | 권리의 작용 → 행사 요건 → 방어 | 형성권의 근거, 동시이행과 소멸의 구별, 제536조 제2항 | 개별 권리의 행사 방식·호의동승·경합을 적용해야 함 | 별도 C 없음 |
| 신의성실·권리남용 | 권리·의무 → 신뢰·행사 → 법규의 한계 | 기능·강행규정·사정변경·금반언의 A 4개, 위험 부담과 예견 가능성 | 누락된 A의 재설명 또는 개별 판례의 추가 사실 비교가 필요 | 별도 C 없음; 후속 범위 완료 처리 금지 |
| 자연인 구간 2 | 행위자 → 동의·예외 → 취소 → 상대방 보호 | 후견별 범위·일상행위 예외, 촉구의 기간·무응답 예외, 철회·거절·속임수 | 동의·후견 등 A 구별이 막히거나 친권자 대리권 남용이 실제 쟁점 | 별도 C 없음 |

검토 결과, 압축할 수 있는 것은 첫 응답에서 모든 판례 세부·운영 설명·출처를 연속 낭독하는 부분이다. 필수 요건을 없애는 대신 하나의 관계 구조에 묶어 설명하고, 어려움을 확인했을 때 기존 상세 설명을 재사용한다. 자연인 단원은 A의 예외가 많아 최초 설명에도 상대적으로 많은 내용이 남는다. 이를 더 줄이려고 후견·상대방 보호를 B로 숨기지 않으며 필요하면 같은 단원 안에서 수업을 나눈다.

새 법리를 추가하지 않았다. 앞서 Korean-law MCP로 확인한 조문·판례와 2026-10-27의 검토 범위를 재사용했고 미대조·미검증 상태를 유지했다. 법리·예외·판례·출처는 기존 강의 안에 보존했다. 파일 전체 분량은 상세 설명을 함께 담아 늘 수 있으므로 총 파일 글자 수 감소를 성과로 주장하지 않는다. 실제 측정할 것은 최초 설명과 필요 보충을 합한 수업 시간·이해·적용·누락이다.

## 시험 자료의 근거와 한계

문제원장에서 1차 지문 10개의 요구능력과 2차의 한 공통 사례에 속한 3개 소문항의 작업 요구를 정리했다. 정답·법리 재검증이나 출제빈도 통계가 아니다. 1차에서는 개념·조건·예외 구별을, 2차에서는 청구 분리·요건 포섭·청구취지 표현을 관찰했다. 시범 단원 밖 사례에서 기초개념의 필요성을 도출한 부분은 교육설계 판단으로 구분했다.

기존 연결 후보 중 시범 단원에 직접 등록된 것은 신의칙 관련 1건이다. 안정키·지문 실존은 확인했지만 원장 미검증 상태는 유지했다. 주제상 관련되는 다른 문제를 확정 연결로 꾸미지 않았다. Google Docs는 수정시각과 일부 키 위치를 확인했으나 정오 표시가 지문 제목에 결합된 구조 때문에 추가 본문 대조를 중단했다. 자세한 조회 범위·한계는 [문제 요구 근거](exam-demand-evidence.md)에 있다.

단기 민법을 주교재로 사용했다. 로앤은 논점별 법리 대조가 확인되지 않아 지도 출처를 공란으로 남겼다. 기존 단원 수준의 위치 후보를 논점별 확인 출처로 바꾸지 않았다. 각 강의에 PDF·Markdown 확인 범위와 법령·판례 근거, 미대조 범위를 표시했다.

## 신의칙 완성형 시범

[실제 ChatGPT 응답 형태의 강의와 후속 대화](teaching-demo.md)에 직접독서와 새 수업의 비교, A/B/C 선정 이유, 핵심 강의, 최산·송민기·정우영 사례의 결론까지 가는 판단 과정, 이해 질문 하나, 재강의, 공식 문제 연결, 오답 보완과 다음 진도를 담았다.

이 시범은 법리를 실제 사실에 적용하는 과정을 보여 준다. 손실이 있다는 사실을 계약 해지 결론으로 바로 연결하지 않고, 계약의 기초·예견 가능성·위험 부담이라는 판단 요소에 사실을 붙여 보여 준다. 답변에서 빠진 요소만 다시 설명하고 필요한 페이지로 돌아간다. 신의칙 단원에서는 필수 요건을 C로 미루지 않았다. 가상 대화는 실제 원답이나 점수로 저장하지 않는다.

## 진도와 성과 확인

[이해도 판단 규칙](../rules/mastery-gate.md)은 직후 이해, 자료 없이 설명, OX, 사례 적용, 지연 기억을 구분한다. 현재 논점의 핵심을 이해하면 잠정 진행하되 확인하지 않은 능력을 완료 처리하지 않는다. 기존 공식 통과·졸업·복습 간격과 수식은 그대로다.

[시범운영 계획](compression-pilot-plan.md)은 직접독서와 AI 수업의 총시간, 보충 독서, 직후·지연 이해, 1차·2차 적용, 누락 논점을 비교한다. 아직 실제 참가자의 전후 자료를 수집하지 않았다. 절감 시간·정답률 향상·기억 유지율은 모두 미측정이다. 1,474쪽을 특정 분량으로 줄이면 합격한다는 목표는 설정하지 않았다.

- 기존 lessons 7개와 [시범 대화](teaching-demo.md): 강의·사례·확인 질문·보충 조건·판단 목표.
- 패키지 검사: 논점ID·원본 단원·분류값·근거 파일·공식 연결키·B/C 승격 조건·미분류 표시 확인. 기존 240개 ID·공식 안정키·회상 파일 보호 검사 유지.

GitHub Actions는 기존 두 검사 명령을 계속 실행한다. 구조 검사는 분류 판단의 교육적 타당성이나 실제 학습효과를 보증하지 않는다. 최종 실행 결과는 PR #1의 Checks와 완료 보고에서 확인한다. 원본 Sheets·Docs와 공식 문제은행은 수정하지 않았고, PB1은 사용하지 않았다. Draft PR은 병합하지 않는다.

실제 ChatGPT 프로젝트에 이전 시작 지침이 붙어 있다면 새 PROJECT_INSTRUCTIONS.md로 갱신해야 한다. 저장소 변경만으로 프로젝트 설정이 자동 교체되지는 않는다. 병합 전에는 작업 브랜치를 명시해서 읽는다.
