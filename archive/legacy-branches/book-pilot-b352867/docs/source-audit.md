## 개념 교육과정

[개념 관리표](https://docs.google.com/spreadsheets/d/1PE_82x6LvkV5lousCroj6ZK3ZYfPDCWCx5tNHck3Umc/edit)의 메타데이터 확인 후 `개념_단원마스터!A4:N250`, `AA4:AC250`을 읽었다. 5~244행에 고유한 단원ID 240개가 있다. 1권 96개, 2권 144개이며 민법총칙 46개·물권법 50개·채권법 86개·가족법 58개다. 학습순서 1~240을 보존했다.

`AB`의 단원별 전용 문항 수 합계는 1,437이다. 이 숫자는 시트가 계산한 문항 수이며 전체 법리 검증 결과가 아니다. `개념_질문큐!A5:B725`에서 질문ID와 단원ID 720쌍을 확인해 색인에 연결했다. 질문 본문 전체와 개인 답변·진도·성적은 복제하지 않았다.

`units-index.csv`의 학습 목표는 목차를 활용해 새로 쓴 교육 목표다. 핵심 논점 필드는 기존 편·장·절·구간 제목이며, 상세 논점 전수 검토와 구분했다. 선수관계는 교재 순서에 따른 제안으로 표시했다. 원본의 출처 검증 문구도 보존했다.

## 단기 민법

[분할 페이지 폴더](https://drive.google.com/drive/folders/1dHJsnaiNiMTrnNaCfaf4L8Nc7vW5Tgjq)에서 64개 항목을 확인했다. Markdown 31개, PDF 31개, 색인 CSV와 검증 요약 각 1개다. 원본 PDF 페이지 범위는 1권 1~622쪽, 2권 1~896쪽이다. 표지·목차 등을 포함한 1,518쪽과 지침의 학습 본문 1,474쪽을 구분한다.

기존 로컬 분할 Markdown 31개를 재사용했다. 240개 단원의 모든 PDF 페이지 표식이 로컬 텍스트에 존재함을 확인했다. 이는 파일·범위 정합 검사이며 OCR 정확성이나 법리 검증이 아니다. 시범 강의의 원문 대조 범위는 각 강의 및 시범 보고서에 별도로 기록한다.

## 보충교재의 표제 확인

Drive 파일명은 [민법(2026년판)_로앤 기본서.pdf](https://drive.google.com/file/d/1yHHW--v8c_VHTOueQSkJ8hi45Uu05IUe/view)다. 실제 표지에는 **리앤핵심시리즈 민법, 리앤법무 연구팀편저, 제3판(2026년판), PDF Vol.260416**으로 표시되어 있다. 파일을 바꾸거나 이름을 수정하지 않고 외부 파일명과 내부 표제를 나누어 기록했다.

PDF는 1,006쪽이다. 텍스트 읽기 도구의 첫 요청은 `Transport closed`로 실패했으나, 인증된 원본 내려받기 후 로컬에서 목차와 필요한 범위를 확인했다. 이 임시 원본은 GitHub 결과물에 포함하지 않는다.

목차 PDF 5~16쪽의 장 제목과 22개 장 시작쪽을 확인했다. 각 시작쪽의 실제 장 제목도 대조했다. PDF 5쪽 목차와 22쪽 본문은 이미지로 확인했다. 본문 19~24쪽은 텍스트로 확인하여 다음 직접 대응을 만들었다.

## 공식 문제 연결

`개념_문제연계!A4:L30`에서 기존 21건을 확인했다. 이 중 20건은 15개 단원에 연결되어 있으며, 기재된 단원ID는 모두 이번 240개 단원 색인에 존재한다. 19행은 단원ID가 공란인 미매칭 1건이다. 해당 안정키는 `SRC-CIV-005|2025-제31회-문1-소문항2`이고 원본 상태도 `검토 필요`다. 임의 단원ID를 부여하지 않았다.

원본의 `Markdown 확인 / PDF 대조 대기`와 `검토 필요`를 그대로 보존했다. 공식 문제원장에서는 헤더 `A4:AI4`만 확인했으며, 연결키의 실재·사용상태는 재검증하지 않았다. 연결표를 출제 근거로 승격하지 않았다.
