## 원문 및 법적 근거

주교재는 기존 검색용 `단기민법_1권_0001-0050.md`다. 대응하는 기존 로컬 `sample-original.pdf`는 50쪽 발췌본이며 위 5쪽을 이미지로 확인했다. 표의 시각 대조는 표본 검증이다. 8~35쪽 전체를 시각 검수했다고 주장하지 않는다. 원본 PDF와 추출 텍스트는 저장소에 복제하지 않았다.

Korean-law MCP에서 민법 lawId `001706`의 제1조·제2조·제98조·제103조·제105조·제106조·제184조·제211조·제536조·제543조·제563조·제750조를 단일 조문 조회로 확인했다. 반환된 공포·시행일은 2026-03-17이다. 배치 조문 조회는 실패했고 단일 조회로 대체했다.

검토 필요 사항: 교재 PDF 9쪽은 91다46885와 계약 요건·절차 설명을 함께 제시하지만, 확인한 판결의 직접 판시사항은 계약금액 감액·환수 조건이다. 첫 강의에서는 사법상 계약이라는 판단과 실제 판시 범위만 사용했다. 계약서 작성 절차 미비에 관한 근거는 별도로 검토해야 한다. 원본 교재·공식 문제·정답키는 변경하지 않았다.

로앤은 다른 담당자가 목차·필요 페이지를 별도로 조사했다. 이 5개 강의에 로앤 법리를 합성하지 않았고 확인된 대응은 `sources/textbook-mapping.csv`를 따른다. 제정 민법 부칙, 국제사법, 각종 무과실책임 유형의 세부 내용 등 이번에 검증하지 않은 부분은 결론을 확장하지 않았다.

## 시범 운영 절차

1. `오늘 민법 과외 시작` 요청을 받으면 현행 시트에서 오늘 학습 대상과 상태를 확인한다. 이 보고서의 순서로 사용자의 진도를 덮어쓰지 않는다.
2. 선택된 단원ID가 위 5개에 있으면 해당 강의 하나만 조회한다. 다른 단원이면 검증된 강의가 준비되지 않았음을 표시하고 현행 원문 조회 절차를 사용한다.
3. 강의 후 회상을 시작한다. 질문 파일만 읽고 한 질문씩 제시한다. 이미 강의에서 본 내용을 즉시 회상한 결과와 장기 기억을 구분한다.
4. 실제 답변을 받은 뒤 해당 강의·출처를 필요한 범위만 재조회한다. 실제 원답을 보존하여 기억함·부분 기억·재복습을 평가한다.
5. 공식 문제로 넘어가면 별도 1차·2차 규칙을 적용한다. 이 강의의 사례로 공식 점수를 만들지 않는다.
6. 완료된 활동만 허용된 시트 영역에 추가하고 기존 자동수식에 복습 계산을 맡긴다. 이번 제작 과정에서는 원본 시트에 쓰지 않았다.

## 완료와 미실시

- 완료: 실제 기존 ID 5개, 독립 강의 5개, 정답 없는 질문 파일 5개, 원문 확인, PDF 표본 대조, 관련 조문·판례 확인, 한글 문체 점검.
- 미실시: 사용자 실제 시범 수업·답안 제출·채점·기록, 학습효과 측정, GitHub에서의 실제 수업 조회 시간 측정, 전체 법리·후속 판례 전수 검증.
- 성능 효과를 수치로 주장하지 않는다. 실제 조회 측정은 `performance-baseline.md`와 향후 동일 조건 시험으로 구분한다.
- 질문과 강의를 파일로 분리한 것은 운영 장치이며 접근 권한 분리가 아니다. ChatGPT가 답변 전 강의를 조회하지 않는 규칙을 함께 지켜야 한다.

# 최신 우선복습에 맞춘 추가 자료 — 2026-10-27

최신 `개념_오늘학습`의 상위 복습 목록과 비교하여 기존 자료에 없던 `B1-P0040-0047`, `B1-P0072-0079` 두 단원만 강의와 질문 전용 회상 파일을 추가했다. 첫 단원은 주교재 PDF 40~47쪽 Markdown 및 원본 44쪽 이미지를 확인했다. 둘째는 PDF 72~79쪽 Markdown을 확인했으며 분할 PDF 시각 대조는 미실시다. 둘째 단원의 검증 상태를 원본 전체 대조 완료로 표시하지 않는다.

민법 제2조·제4~10조·제12~13조·제14조의2·제15~17조를 Korean-law MCP로 확인했다(반환 시행일 2026-03-17). 판례 전문 확인 범위는 [94다42129](https://www.law.go.kr/LSW/precInfoP.do?precSeq=112987), [2016다249557](https://www.law.go.kr/LSW/precInfoP.do?precSeq=185165), [2005다71659 등](https://www.law.go.kr/LSW/precInfoP.do?precSeq=126079), [2016다3201](https://www.scourt.go.kr/sjudge/1525075721337_170841.pdf)이다. 후속 판례 전수 검증은 하지 않았다. 2005다71659 등의 당시 성년 연령과 현행 19세를 구별하고, 신의칙 법리와 묵시적 처분허락에 따른 실제 결론을 분리했다.

기존 공식 문제·개념 전용문제의 본문과 채점키를 가져오지 않았다. 추가 회상 질문은 독립 작성했으며 기존 질문큐 Q1~Q3의 대체물이 아니다. 개인 원답·완료 기록도 만들지 않았다. `units-index.csv`의 두 기존 행에만 강의·회상 경로와 작성 상태를 연결했다. 새 단원ID는 없다.
