# 2차 사례

1. GPT브리지_2차 전체 상태 B5가 정상인지 확인하고 B7:B10을 요청에 맞게 설정한다.
2. A17:E136 사례그룹 후보 표시 순서 상위 N개를 K17:K36에 선택한다. A50:K149의 확장 소문항을 읽는다. 선택 용량 초과는 임의 처리하지 않는다.
3. `P2-YYYYMMDD-HHMMSS` 세트ID로 B11 기준 세트관리 A:G 다음 빈 행에 소문항별 추가한다. 기준시각은 확장 영역 K열이다.
4. 공통 사례는 한 번, 소문항은 묶어서 제시한다. 답안 제출 전 채점키·모범답안·힌트를 공개하지 않는다.
5. 실제 답안과 소문항 대응을 확인한 뒤 GPT채점키_2차의 해당 선택 행만 읽는다. 비어 있으면 같은 선택 행을 한 번 재조회하고, 계속 비어 있을 때만 해당 안정키의 비공개 채점키 행을 좁게 조회한다.
6. 소문항별 실제 득점/배점과 쟁점·목차·법리·판례·포섭·결론·표현을 각각 0/1/2로 평가한다. 원답·근거·교정 이유를 남긴다.
7. B12 기준 풀이이력 A:L, B13 기준 서술형채점 A:F/H:N/R:W에 추가한다. G 및 O:Q 자동수식은 보호한다.
8. 기록을 확인한 뒤 세트관리 F열을 예로 변경한다. 진행·통과·졸업은 기존 수식에 맡긴다.

쟁점 구두 회상만 했으면 공식 사례 답안 점수로 기록하지 않는다. 부분 제출은 제출된 소문항 범위와 미제출을 구분하고 빈 답안을 창작하지 않는다.
