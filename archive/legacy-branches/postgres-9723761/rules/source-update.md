# 문제 자료 갱신

Google Docs는 갱신 입력원, 공식 Sheets는 정식 출제·채점 기준이다. 원문 변경을 감지해도 원장을 자동 덮어쓰지 않는다.

변경분을 신규·본문수정·중복후보·삭제후보·정답/해설변경·연결보강으로 구분한다. 기존 안정키는 유지하고 문항 버전과 출처 버전을 구별한다. 과거 풀이를 재채점하지 않는다.

실제 도입 전 docs/sync-design.md의 검토·승인·백업·적용·검증 절차를 따른다. 정답 관련 비교는 일반 학습 경로와 분리된 명시적 유지보수 권한 없이는 수행하지 않는다. 이번 구축에서는 채점키 비교를 실행하지 않았다.
