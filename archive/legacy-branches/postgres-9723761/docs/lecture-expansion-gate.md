# 민법 강의 확대 관문

`python tools/lecture_readiness.py`는 240개 단원의 강의 준비 상태를 읽기 전용으로 집계한다. `--details`는 부족한 단원 ID를, `--require-complete`는 전체 강의 준비가 끝나지 않았을 때 실패 코드를 반환한다. 형식 통과는 법리 정확성 인증이 아니다.

단원 확대 순서:

1. 인접 단원의 기본서 Markdown 범위와 실제 PDF 쪽을 대조하고, 출처 버전·확인일을 기록한다. 연결된 Drive 파일을 읽을 수 있어도 PDF 쪽 대조를 생략하지 않는다.
2. 해당 범위의 요건·효과·중요 예외·판례 기준을 추출하고, 국가법령정보센터 법령·판례 원문으로 현행성과 적용 범위를 확인한다. 확인 못 한 쟁점은 미검증으로 둔다.
3. A/B/C 등급은 선수관계와 설명 필요성으로 분류한다. 출제빈도나 공식 문제 연결을 임의로 추론하지 않는다.
4. 1층 핵심 강의, 2층 조건부 보충, 창작 사례, 이해 확인 질문, 1차 구별·2차 목차를 작성한다. 기본서 문장을 복제하지 않는다.
5. 출처·검증 상태를 `units-index.csv`와 논점 지도에 반영하고, `validate_package.py`와 이 관문을 실행한다. 법리 검토자가 원문 대조와 누락 검사를 마친 단원만 PostgreSQL 활성 강의로 올린다.

현재 인접 `B1-P0036-0039`는 상세 논점 미분류, PDF 단원별 직접 대응 미확정이다. 강의 원문을 추측해 제작하거나 `available`로 활성화하면 안 된다.

전체 완료 판정은 별도 사람의 법리 검토 증빙, 240개 활성 강의의 DB 매핑, ChatGPT 실제 수업 인수시험이 모두 필요하다.
