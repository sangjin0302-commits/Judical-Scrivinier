# 민법 2차 모범답안 대조 계약

1. 출제 응답에는 공식 답안·채점기준을 넣지 않는다. 실제 원답을 `prepareCivilP2Grade`로 확정한 뒤 해당 세트에 묶인 공식 모범답안과 채점기준을 조회한다.
2. 모범답안에서 필수 쟁점, 법리, 요건, 판례, 사안포섭, 결론을 의미 단위로 추린다. 적용되지 않는 범주를 억지로 만들지 말고 `decompositionRationale`에 제외 이유를 적는다. 각 요소의 공식 근거는 `modelExcerpt`로 지정한다.
3. 원답의 의미를 읽어 `MATCH`, `PARTIAL`, `MISSING`, `ERROR`, `ALTERNATIVE_ACCEPTED` 중 하나로 판정한다. `MATCH`는 원답 근거 `answerExcerpt`가 필요하다. 단어 일치, 길이, 문자열 유사도를 채점 근거로 삼지 않는다.
4. 다른 표현과 타당한 대체 논증을 인정한다. 공식 답안과 다른 법리를 인정할 때는 법령·판례 등의 확인 가능한 출처를 `alternativeSourceRef`에 기록한다. 출처 확인 전에는 대체 법리 인정으로 표시하지 않는다.
5. 핵심요소 일치율은 완전 일치 및 검증된 대체 논증의 **건수 ÷ 전체 추린 요소 건수**다. 부분 일치는 별도 건수로 표시한다. 이 비율은 학습 진단값이며 배점 공식이 아니다.
6. `awardedPoints`는 기존 공식 최대 배점 안에서 판단한다. 기존 7요소 점수도 유지한다. `scoreRationale`에 어느 공식 기준과 원답 근거를 사용했는지 적는다. 공식 기준에 없는 요소별 가중치를 새로 만들지 않는다.
7. `commitCivilP2Grade`는 공식 자료와 원답의 근거 발췌문이 실제 존재하는지 검사한다. DB에는 발췌문 대신 해시와 판정 근거를 저장한다. 동일 제출 재시도는 기존 결과를 돌려주고, 다른 평가는 거부한다. 기존 확정 답안을 재채점하지 않는다.

`modelExcerpt`와 `answerExcerpt` 검사는 출처 연결 확인이다. 의미 판정의 자동 정확성을 보증하지 않는다. 실제 채점 일관성은 사람 검토 표본과 같은 원답의 반복 평가로 별도 검증한다.
