# 갱신 실행 전 점검표

실제 증분 갱신은 아직 활성화하지 않았다. 정본 설계는 [sync-design.md](sync-design.md)다.

1. Google Docs 개정 신호와 마지막 승인 버전을 비교한다.
2. 필요한 변경 구간만 확보하고 원본 ID와 기존 안정키를 대조한다.
3. 신규·수정·중복·삭제후보·정답변경·연결보강을 분리한다.
4. 검토 보고에는 키와 변경 범위만 쓰고 정답·공식 지문은 GitHub에 올리지 않는다.
5. 별도 승인 및 백업 후 검증환경에서 시험한다.
6. 검증된 변경만 원본 적용 대상으로 제시한다. 이번 구축에서는 5~6단계를 실행하지 않는다.

일상 수업 중 원문 갱신을 발견하면 해당 키의 검토 필요를 보고하고, 공식 답을 임의로 바꾸거나 이전 이력을 재채점하지 않는다.
