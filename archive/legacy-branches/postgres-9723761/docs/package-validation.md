# 확장 가능한 패키지 검사

강의가 늘거나 공식 문제 연결 후보가 추가돼도 수량만으로 실패하지 않도록 검사를 바꿨다. 기준은 파일 개수가 아니라 기존 식별자 보존, 연결 관계, 출처 메타데이터다.

`tools/identity-baseline.json`은 이번 보완 전 커밋의 단원ID 240개와 권·PDF 범위, 공식 문제 안정키를 보존한다. 새 강의와 회상 파일은 기존 단원ID로 추가하고 교육과정 색인의 경로도 함께 갱신한다. 연결 후보는 늘릴 수 있지만 기존 공식 안정키를 삭제하거나 바꾸면 실패한다. 기준 파일 자체의 변경은 원본과 대조하는 별도 검토 대상이다.

## 실패와 경고

실패는 식별자 변경·누락, 중복 연결, 알 수 없는 단원, 깨진 강의·회상 경로, 잘못된 출처 메타데이터 등 패키지 구조 문제를 뜻한다. 이때 명령은 0이 아닌 종료코드를 반환해 PR 검사를 실패시킨다.

기존 원본에 있던 단원ID 공란은 해결됐다고 처리하지 않는다. 해당 안정키를 경고로 출력한다. 원본 근거로 공란을 해결하면 경고가 사라질 수 있으며, 공란을 반드시 1개 유지하도록 강제하지 않는다. 새 연결의 공란은 실패로 보고한다.

공식 문제 연결의 원본 재검증 여부도 출력한다. 구조 검사가 통과해도 미검증 연결을 검증 완료로 인정하지 않는다. 기존 자료에는 연결 후보 21건과 단원ID 공란 1건이 있으며, 이 숫자는 현황 설명이지 앞으로의 고정 검사 조건이 아니다.

## 검증 범위

출처 검사는 HTTPS·Google 파일ID·색인 연결 같은 저장소 내부 메타데이터 검사다. 원격 파일의 현재 접근권한, 삭제 여부, 교재 본문의 정확성은 온라인 조회가 필요한 별도 검토다. CI에서 Google에 접속하지 않는다.

회상 파일의 정답 제목 검사도 보조 수단이다. 제목 없이 본문에 섞인 정답까지 자동으로 판정하지 않으므로 게시 전 사람이 내용을 확인해야 한다. 합성 회귀 테스트는 강의·연결 확장과 손상 사례를 임시 폴더에서 검사하며, 원본 학습자료나 실제 기록을 변경하지 않는다.

실행 방법과 PR 확인 위치는 [자동 검사 안내](ci-checks.md)를 따른다.
