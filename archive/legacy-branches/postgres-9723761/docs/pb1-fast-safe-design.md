# PB1 고속·안전 v2 설계

기준일: 2026-10-28 KST. 이 문서는 테스트 사본용 설계다. 운영 원본 수정·PB1 실행·배포 승인을 뜻하지 않는다.

## 사용자 동작

1. 화면에서 **10문제 출제**를 한 번 누른다.
2. O/X를 모두 선택한다.
3. **답안 제출·채점**을 한 번 누른다.

화면은 Apps Script HTML Service만 사용한다. 별도 웹앱 서버, Railway, Vercel, 유료 OpenAI API가 없다. PC와 모바일 폭에서 한 열로 표시한다.

## 출제 한 번 호출

`PB1F_issue({requestId})`가 ScriptLock 안에서 아래 작업을 끝낸다.

1. 테스트 사본 ID인지 확인한다. 운영 원본 ID면 즉시 중단한다.
2. `GPT브리지_1차!B5`가 `정상`인지 확인한다.
3. `1차통합설정 A:D`의 활성 범위와 문항수를 읽는다. 현재 설정이 총칙 3·물권법 7이면 그대로 따른다. 설정값 자체가 최신 학습범위라는 주장은 하지 않는다.
4. 매 요청마다 새 시드를 만든다.
5. 범위별로 기존 브리지 B7:B10을 설정하고, 브리지가 표시한 후보 A17:H136의 상위 N개 안정키를 그대로 취한다. 문제원장 필터를 별도로 재구현하지 않는다.
6. 영역 간 중복과 총 40문항 한도를 검사한다.
7. 합친 안정키를 K17:K56에 쓰고 L:S의 공개 문제 정보만 읽는다.
8. `P1-YYYYMMDD-HHMMSS`로 세트관리 A:G에 등록하고 재조회한다. 성공 뒤에만 공개 E를 `예`로 바꾼다. 제출 F는 `아니오`로 남긴다.
9. 문제·세트ID·총 소요시간을 한 응답으로 반환한다.

같은 `requestId` 재호출은 새 세트를 만들지 않고 기존 세트를 복원한다.

## 채점 한 번 호출

`PB1F_grade({setId, answers})`가 ScriptLock 안에서 아래 작업을 끝낸다.

1. 세트 문항수·순서·안정키 중복·O/X 형식을 확인한다.
2. 해당 세트 안정키만 K17:K56에 복원한다.
3. 답안 제출 뒤에만 `GPT채점키_1차 A5:G44`를 읽는다. 현재 선택 최대 40행이며 전체 키 탭을 읽지 않는다.
4. OX정답키 A:G와 풀이이력 A:L의 기존 동일 세트·안정키를 대조한다.
5. 없는 행만 추가한다. 이미 같은 값이면 재사용하고, 값이 다르면 충돌로 중단한다.
6. 재조회하여 문항수·안정키·원답·점수와 보호 수식 OX H, 풀이 M을 확인한다.
7. 모든 검증이 끝난 뒤에만 세트관리 F를 `예`로 바꾼다.

OX 기록 뒤 풀이 기록이 실패해도 기존 행을 지우지 않는다. 같은 제출을 재시도하면 빠진 행만 추가한다. 이는 append-only 원칙을 지키는 부분 실패 복구다.

## 보호 범위

- 쓰기: 세트관리 A:G, OX정답키 A:G, 풀이이력 A:L, 브리지 설정·선택 셀만 사용한다.
- 비쓰기: OX정답키 H, 풀이이력 M:Q, 문제원장, 비공개 원본 채점키, 기존 이력.
- 답안 전: `GPT채점키_1차` 접근 없음.
- 테스트 코드: Google 서비스에 연결하지 않는 합성 메모리 모델만 사용한다.

## 현행 PB1 대비

| 항목 | 현행 PB1 | v2 테스트 소스 |
|---|---|---|
| 후보 | 문제원장 필터 재구현, 기존 브리지와 불일치 | 기존 브리지 표시 상위 N개 직접 사용 |
| 세트ID | `TEST-P1-*` | `P1-*`, 중복 검사 |
| 시드 | 기존 숫자 재사용 가능 | 요청마다 새 시드 |
| 키 조회 | 채점키 시트 전체 | 선택 40행 A:G |
| 제출 표시 | 기록 전에 `예` | 전체 재검증 뒤 `예` |
| 동시성 | 없음 | ScriptLock |
| 재제출 | 중복 가능 | 동일 값 멱등, 충돌 거부 |
| 부분 실패 | 복구 없음 | 누락 행만 append 후 재검증 |

## 운영 승격 전 필수 증거

테스트 사본에서 다음을 모두 측정·기록해야 한다.

- 동일 설정·동일 시드에서 기존 브리지 표시 상위 N개와 결과가 일치한다.
- 답안 전 실행 로그에 채점키 읽기가 없다.
- 합성 답안의 점수와 기록이 일치하고 보호 수식이 유지된다.
- 동시 출제·동시 제출에서 중복 기록이 없다.
- OX 기록 직후 강제 실패 후 재시도로 정확히 복구된다.
- PC·모바일 브라우저에서 10문항 선택과 제출이 가능하다.
- 기존 다중 도구 중계와 v2의 출제 전체시간·채점 전체시간을 같은 테스트 사본·같은 10문항 조건에서 각각 5회 이상 측정한다.

실측 전에는 속도 개선을 주장하지 않는다.
