# 시트 접근 계약

기준일 2026-10-27. 실제 기록 실행 전 원본 헤더·포인터 재확인. 이번 작업은 읽기 전용이다.

| 경로 | 설정·선택 | 출력·기록 | 보호 |
|---|---|---|---|
| 1차 기존 브리지 | B7:B10, K17:K56 | 후보 A17:H136, 선택 L:S; B11 세트관리 A:G, B12 OX정답키 A:G, B13 풀이이력 A:L | OX정답키 H, 풀이이력 M:Q |
| 2차 기존 브리지 | B7:B10, K17:K36 | 후보 A17:E136, 확장 A50:K149; B11 세트관리 A:G, B12 풀이이력 A:L, B13 서술형채점 A:F/H:N/R:W | 서술형채점 G/O:Q |
| 개념 회상 | 실제 원답 제출 | 개념_회상이력 A:L 다음 빈 행 | 단원마스터 O:Z, AB:AC 등 자동 계산 |
| 통합 1차 | 1차통합설정 A3:D8 및 기존 PB1 함수 | GPT통합브리지_1차 결과; 함수 계약 별도 확인 | 기존 기록·정답 접근 조건 |

개념_회상이력 A:L: 실제 기록일, 단원ID, 회상세트ID, 활동구분, 실제 회상 원답, 회상평가, 누락·교정 기록, 학습시간, 원답 확인, 기본서 출처, 공식 안정키, 비고.

1차 세트관리 F는 실제 채점 기록 확인 후에만 예로 전환한다. 기록 위치는 시트의 포인터를 사용하되 쓰기 직전 대상 빈칸도 검증한다. 대형 수식 때문에 getLastRow를 다음 기록행으로 대체하면 안 된다.

배치 쓰기는 의존 순서를 없애지 않는다. 상태확인 → 설정 → 후보 읽기 → 상위 선택 → 세트 등록 → 문제 제시 → 실제 제출 → 채점키 → 기록 → 검증 순서를 지킨다. 서로 다른 세트의 선택칸을 동시에 쓰지 않는다.

이 계약은 사용자 지침과 확인한 표본의 요약이다. 정확한 전체 열 정의는 기존 v3가 우선한다. 임의로 새로운 입력열을 추가하지 않는다.
