# B1-P0008-0011 · 민법의 의의 회상

질문 전용 v1.0. 답변 전에는 `lessons/`나 교정 근거를 조회하지 않는다. 질문을 한 번에 하나씩 제시하고 원답을 그대로 받는다. 아래 질문은 새로 작성한 개념 연습이며 공식 문제은행 문항이 아니다.

1. 실질적 의미의 민법과 형식적 의미의 민법을 어떤 기준으로 나누는가?
2. 일반법과 특별법은 무엇이 다르며, 구별하면 어떤 판단에 도움이 되는가?
3. 최산이 송민기에게 물건값을 요구한다. 권리가 있는지 판단하는 일과 소송으로 받아내는 일은 어떤 차이가 있는가?
4. 정우영은 국가가 계약 당사자이면 언제나 공법관계라고 말한다. 어떤 사정을 확인해야 하는가?
