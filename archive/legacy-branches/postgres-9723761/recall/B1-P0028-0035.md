# B1-P0028-0035 · 법률관계와 권리·의무 회상

질문 전용 v1.0. 답변 전에는 강의·교정 근거를 조회하지 않는다. 한 문항씩 원답을 받는다. 공식 문제은행 문항이 아닌 개념 연습이다.

1. 지배권·청구권·형성권·항변권을 작용에 따라 설명하라.
2. 권한·권능·권원을 구별하고 각각 예를 들어라.
3. 최산과 송민기의 매매에서 양쪽 의무의 이행기가 되었다. 최산은 물건 인도를 제공하지 않으면서 대금부터 요구한다. 정우영이 정리해야 할 청구와 항변은 무엇인가?
4. 해제 의사를 표시했다는 사실만으로 계약이 언제나 해제되는가? 먼저 확인할 사항은 무엇인가?
5. 무료로 차를 태워 주었다가 사고가 났다. 호의라는 사정이 책임 유무와 배상액 판단에서 어떤 의미를 갖는가?

제출 후 처리: 같은 ID의 강의에서 필요한 근거를 읽고, 실제 원답에 한해 기억함·부분 기억·재복습으로 평가한다. 미제출 답변이나 공식 시험 점수를 생성하지 않는다. 기록은 `rules/concept-recall.md`를 따른다.
