# B1-P0028-0035 · 법률관계와 권리·의무

강의 v4.0 · 검토 기준일 2026-10-27 · 학습용 일반 설명.

## 1층: 최초 핵심 수업

상대방에게 돈을 달라는 말과 상대방도 이행할 때까지 거절한다는 말은 다른 법적 작용이다. 권리의 이름보다 그 작용을 알아야 사례에서 청구와 방어를 나누어 쓸 수 있다.

A 4개를 `무슨 권리인가 → 행사 요건 → 상대방의 방어`로 묶는다. 형성권의 근거, 동시이행 항변의 요건·선이행 예외, 권한·권능·권원을 유지한다.

### 최소 구조와 필수 법리

1. 법률관계는 법이 규율하는 생활관계다. 매매에서는 대금 지급과 재산권 이전의 권리·의무를 양쪽에 놓는다. 소유권 같은 지배권, 행위를 요구하는 청구권, 법률관계를 바꾸는 형성권, 청구의 작용을 저지하는 항변권을 구별한다.
2. 제543조의 해제·해지는 계약 또는 법률상 권리가 있어야 행사할 수 있다. 일방적으로 말한다고 해제권이 새로 생기지 않는다. 형성권 중에는 판결이 필요한 유형도 있으므로 모두 의사표시만으로 완성된다고 일반화하지 않는다.
3. 제536조의 동시이행 항변은 상대방의 이행제공까지 자기 이행을 거절하는 구조다. 상대방 채무가 변제기에 있는지 등을 확인한다. 선이행 의무가 있어도 상대방 이행이 곤란할 현저한 사유가 있는 제2항의 경우는 따로 검토한다. 항변으로 상대방 채권이 소멸하는 것은 아니다.
4. 권한은 타인을 위하여 법률효과를 일으킬 지위·자격, 권능은 권리를 이루는 개별적인 힘, 권원은 행위를 정당화하는 원인이다. 대리권, 소유권의 사용·수익·처분, 사용 근거인 임차권의 예를 서로 바꿔 쓰지 않는다.

### 짧은 완결 사례

최산은 자전거 판매자, 송민기는 구매자, 정우영은 두 사람의 말을 정리하는 친구다. 서로의 채무 이행기가 되었고 선이행 약정은 없다고 가정한다. 최산은 자전거 인도를 제공하지 않은 채 대금을 요구한다. 송민기는 자전거를 제공할 때까지 대금 지급을 거절하겠다고 한다.

최산의 말은 대금청구이고 송민기의 말은 동시이행 항변이다. 제536조에 따라 같은 쌍무계약의 대가관계, 변제기, 이행제공 여부를 확인하면 이 가정에서는 송민기가 지급을 거절할 수 있다. 정우영은 이를 '대금채무가 없어졌다'고 정리해서는 안 된다. 인도 제공이 이루어졌을 때는 항변을 유지할 수 있는지 다시 판단한다.

### 확인 질문과 진행

질문 하나: 송민기가 지금 지급을 거절할 수 있다는 것이 대금채무가 없어졌다는 말과 왜 다른가?

청구의 존재와 이행 거절의 조건을 나누어 설명하면 다음으로 진행한다. 막히면 최산과 송민기의 말을 한 문장씩 다시 풀어 준다. 즉시 이해를 지연 기억 성공이나 공식 점수로 저장하지 않고 백지복습은 명시 요청 때만 기존 recall을 사용한다.

## 2층: 조건부 보충 수업

첫 설명에서는 이 층을 한꺼번에 읽어 주지 않는다. 1층의 A 요건을 빠뜨린 답변에는 해당 A를 다시 설명하고, 새로운 B 논점이 실제로 등장할 때 B를 보충한다. 설명 층과 A/B/C 등급은 서로 다르다.

### 해당 쟁점이 드러날 때 — B 논점 상세 보충

무료로 도와줬으니 법적 책임도 없다고 생각하면 95다24302의 호의동승을 보충한다. 단순한 호의동승만으로 배상액이 바로 줄지는 않으며 운행 목적·관계·경위 등을 살핀다. 형성권의 구체적 행사 방법을 틀리면 PDF 33쪽 표에서 해당 권리만 다시 확인한다. 개별 청구권 경합은 필요한 판례를 추가 확인한다.

### 유예 범위를 확인할 때 — C 지정 없음

확인한 범위에서 별도로 유예할 논점을 지정하지 않았다. 요건·효과·예외를 줄여야 한다는 뜻은 아니며, 이미 이해한 정의의 반복 낭독을 줄이는 것은 수업 운영 방식이다. 새로운 사례에서 부족한 점이 확인되면 B의 해당 근거를 보충한다.


## 공통 — 정상 진행과 근거 확인

공식 문제 적용과 출처 확인은 오답이 없어도 수업 준비·정상 진행에 필요할 때 수행한다. 조건부 재강의만을 위한 절차가 아니다.

### 공식 문제 적용으로 넘어갈 때 — 1차 구별·2차 목차

1차는 청구권·형성권·항변권과 권한·권능·권원을 작용으로 구별한다. 2차 목차는 `청구 근거와 요건 → 상대방 항변의 요건 → 이행제공 등 사실의 포섭 → 결론`이다.


### 근거를 확인할 때 — 출처와 미검증 범위

- 주교재: `단기민법_1권_0001-0050.md`, PDF 28~35쪽. 형성권 표가 있는 PDF 33쪽 시각 대조.
- 법령: 민법 제211조·제536조·제543조·제563조·제750조. Korean-law MCP lawId `001706`, 반환 시행일 2026-03-17.
- 판례: [95다24302 공식 원문](https://www.law.go.kr/LSW/precInfoP.do?precSeq=113413), Korean-law MCP ID `113413` 전문 확인.
- 권리분류는 교재의 학습 체계에 따른 설명. 청구권 경합의 개별 판례와 교재의 모든 권리 예시는 전수 검증하지 않음. 로앤 법리 미합성.

A/B/C는 선수 관계와 현재 설명 필요성에 따른 교수 판단이다. 실제 출제빈도나 검증된 공식 문항 연결을 뜻하지 않는다. 원본 브리지의 정상 상태·후보 순서를 따르며 답안 제출 전 채점키를 읽지 않는다.


### 공식 연결을 확인할 때 — 표본 근거와 한계

2차 표본의 여러 청구를 나누고 청구취지로 표현하는 요구를 관찰했다. 권리·청구·항변 구별을 A로 유지한 것은 선수학습 설계다. 해당 표본의 기존 직접 연결은 다른 단원이며 이번 강의로 바꾸지 않는다. 자세한 표본·조회 범위·미확인 한계는 [시험 요구능력의 확인 근거](../docs/exam-demand-evidence.md), 논점별 A/B/C는 [논점 지도](../curriculum/issue-map.csv)를 따른다. 원문·정오를 이 강의에 복제하지 않았으며 출제빈도는 산정하지 않았다.
