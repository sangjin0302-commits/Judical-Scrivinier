# B1-P0019-0023 · 민법의 기본원리

강의 v4.0 · 검토 기준일 2026-10-27 · 학습용 일반 설명.

## 1층: 최초 핵심 수업

계약은 자유롭게 정하지만 어떤 약정이든 유효하지는 않다. 손해가 생겨도 언제나 상대방이 배상하는 것은 아니다. 자유와 책임을 구체적 요건으로 연결하기 위해 이 단원을 배운다.

A 3개를 `자유 → 법적 한계 → 손해배상 요건`으로 묶는다. 소유권의 법률상 범위, 고의·과실 등 책임 요건, 교섭상 신뢰와 손해의 연결을 유지한다.

### 최소 구조와 필수 법리

1. 사적자치는 자신의 법률관계를 스스로 정하고 책임지는 원칙이다. 제105조는 임의규정과 다른 의사를 존중한다. 강행규정과 제103조의 사회질서 위반은 별도 한계이며, 사회질서에 위반하는 법률행위는 무효다.
2. 소유권은 사용·수익·처분을 포함하지만 제211조의 법률의 범위 안에서 행사한다. 과실책임의 기본인 제750조는 고의·과실, 위법행위, 손해와 인과관계를 요구한다. 손해 발생만으로 책임을 정하지 않는다.
3. 계약을 맺지 않을 자유에도 신뢰보호의 한계가 있다. 계약 체결이 확실하다는 정당한 신뢰를 주고 상대방이 그에 따라 행동했는데 상당한 이유 없이 체결을 거부하여 손해를 입히면 불법행위가 문제 된다. 배상은 상당인과관계 있는 신뢰손해이며 기대한 계약 이익 전부와 같지 않다(2001다53059).

### 짧은 완결 사례

최산과 송민기가 계약을 협의하고 정우영은 송민기의 준비 비용을 정리한다. 최산이 계약 체결을 확실하게 믿도록 해 별도 준비를 시켰다가 상당한 이유 없이 거절했다고 가정하자. 송민기는 계약상 이익을 곧바로 청구한다고 쓰기 전에 계약 성립 여부와 교섭 과정의 불법행위를 나눈다. 제750조와 2001다53059의 기준에 따라 정당한 신뢰, 그에 따른 행동, 부당한 파기, 손해의 연결을 확인한다. 정우영의 비용표 중 확고한 신뢰가 생기기 전에 협상 무산을 예상하며 쓴 비용과 그 뒤 신뢰 때문에 쓴 비용은 같게 취급하지 않는다. 후자의 상당인과관계 있는 손해가 배상 검토 대상이며 금액 전부가 자동 인정되는 것은 아니다.

### 확인 질문과 진행

질문 하나: 송민기의 준비 비용을 모두 한꺼번에 배상 대상이라고 할 수 없는 이유는 무엇인가?

신뢰 형성 시점과 비용 지출의 연결을 설명하면 다음 논점으로 진행한다. 막히면 비용표를 신뢰 형성 전후로 나누어 다시 설명한다. 즉시 이해는 채팅에서 확인하고 지연 복습 성공·공식 점수로 저장하지 않는다. 백지복습은 명시 요청 때만 기존 recall을 사용한다.

## 2층: 조건부 보충 수업

첫 설명에서는 이 층을 한꺼번에 읽어 주지 않는다. 1층의 A 요건을 빠뜨린 답변에는 해당 A를 다시 설명하고, 새로운 B 논점이 실제로 등장할 때 B를 보충한다. 설명 층과 A/B/C 등급은 서로 다르다.

### 해당 쟁점이 드러날 때 — B 논점 상세 보충

비용을 모두 배상받는다고 답하면 PDF 20쪽과 2001다53059의 신뢰손해 부분을 보충한다. 무과실책임 사례가 나오면 해당 특별책임 규정의 요건을 따로 확인한다. 이번 강의에서 특별책임 제도를 모두 검증했다고 보지 않는다.

### 학설 비교가 실제로 필요할 때 — C 승격

교재 PDF 19쪽의 민법 최고원리에 관한 공공복리설·사적자치원칙설의 학설 대립은 배경 논점으로 유예한다. 이번 사례에 필요한 계약자유의 한계와 신뢰손해 판단은 A에서 이미 설명하므로, 최고원리를 둘러싼 학설 이름을 먼저 암기할 필요는 없다는 교수 판단이다. 출제되지 않는다는 뜻은 아니다. 실제 문항이 그 대립을 요구하거나 원리의 관계를 설명하지 못하는 원인이 되면 B로 올려 해당 쪽을 확인한다.


## 공통 — 정상 진행과 근거 확인

공식 문제 적용과 출처 확인은 오답이 없어도 수업 준비·정상 진행에 필요할 때 수행한다. 조건부 재강의만을 위한 절차가 아니다.

### 공식 문제 적용으로 넘어갈 때 — 1차 구별·2차 목차

1차는 계약자유를 무책임과 같게 보거나 신뢰손해를 이행이익과 같게 보지 않는다. 2차 목차는 `계약 성립 여부 → 교섭상 신뢰 형성 → 거절의 정당성 → 불법행위 요건 → 손해 범위`다.


### 근거를 확인할 때 — 출처와 미검증 범위

- 주교재: `단기민법_1권_0001-0050.md`, PDF 19~23쪽. 계약교섭 판례가 있는 PDF 20쪽 시각 대조.
- 법령: 민법 제2조·제103조·제105조·제211조·제750조. Korean-law MCP lawId `001706`, 반환 시행일 2026-03-17.
- 판례: [2001다53059 공식 원문](https://www.law.go.kr/LSW/precInfoP.do?evtNo=2001%EB%8B%A453059&mode=0), Korean-law MCP ID `194584` 전문 확인.
- 로앤 법리 미합성. 기본서의 모든 무과실책임 예시를 검증·재수록하지 않음. 후속 판례 전수 추적 미실시.

A/B/C는 선수 관계와 현재 설명 필요성에 따른 교수 판단이다. 실제 출제빈도나 검증된 공식 문항 연결을 뜻하지 않는다. 원본 브리지의 정상 상태·후보 순서를 따르며 답안 제출 전 채점키를 읽지 않는다.


### 공식 연결을 확인할 때 — 표본 근거와 한계

2차 표본의 사실 분류·청구별 검토에 필요한 원칙과 책임 요건을 선수학습으로 유지했다. 이 단원의 교섭상 신뢰 사례와 직접 연결된 공식 문항을 확인한 것은 아니다. 자세한 표본·조회 범위·미확인 한계는 [시험 요구능력의 확인 근거](../docs/exam-demand-evidence.md), 논점별 A/B/C는 [논점 지도](../curriculum/issue-map.csv)를 따른다. 원문·정오를 이 강의에 복제하지 않았으며 출제빈도는 산정하지 않았다.
