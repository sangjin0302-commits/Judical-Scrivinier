# 실제 학습 대상과 시범 강의의 대응

확인 기준: 2026-10-27, 개념 원본 Google Sheet 읽기 전용 조회. 이 문서는 준비 상태만 기록한다. 실제 수업·답안 제출·채점·시트 기록을 완료했다는 보고가 아니다.

## 이번에 확인한 범위

[개념 관리표](https://docs.google.com/spreadsheets/d/1PE_82x6LvkV5lousCroj6ZK3ZYfPDCWCx5tNHck3Umc/edit)의 메타데이터를 확인한 뒤 `개념_오늘학습!A1:N14`, `A15:G40`, `개념_설정!A4:C11`, `개념_문제출제큐!A1:M13`을 읽었다. 신규 제작 대상의 정적 정보는 `개념_단원마스터!A10:N20`과 기존 교육과정 색인으로 확인했다.

현재 추천 대상과 첫 5개 강의를 대조한 결과, 기존 강의로 모든 대상을 다룰 수는 없었다. 빠진 두 단원을 추가 제작 대상으로 정했다. 원답, 평가 등급, 개인별 복습 예정일과 상세 학습이력은 이 문서에 저장하지 않는다.

## 기존 질문 재사용

전용 문제은행에서는 단원ID로 좁게 검색하고 문항ID·단원ID 두 열만 반환받았다. `A5:B120` 안에서 다음 등록을 확인했다.

| 단원ID | 원본 문항ID | 확인 위치 | 등록 수 |
| --- | --- | --- | ---: |
| B1-P0040-0047 | CB-B1-P0040-0047-01 ~ -07 | 개념_전용문제은행 A39:B45 | 7 |
| B1-P0072-0079 | CB-B1-P0072-0079-01 ~ -07 | 개념_전용문제은행 A71:B77 | 7 |

기존 일반 회상 질문ID는 각각 `B1-P0040-0047-Q1~Q3`, `B1-P0072-0079-Q1~Q3`이며 이전의 `개념_질문큐!A5:B725` 확인 결과를 재사용한다. CB 문항, 기존 Q 문항, 저장소의 별도 회상 연습은 서로 다른 자료다. 새 질문을 기존 ID의 내용으로 덮어쓰지 않는다.

전용 문제은행 문항의 본문과 정답을 저장소에 복제하지 않는다. 실제 수업에서 기존 문항을 사용할 때만 해당 행의 질문과 원문 위치를 읽는다. 답변 전에는 강의의 교정 근거나 판례 결론을 덧붙이지 않는다. 등록 문항 수는 법리 검증 완료 수가 아니다.

## 공식 문제 연결

이번 확인은 개념 수업의 준비 범위다. 공식 OX·사례를 출제하거나 채점키를 읽지 않았다. 기존 `mapping/concept-problem-proposals.csv`의 연결 상태를 재사용하되, 이를 정식 출제 세트로 바꾸지 않는다. 공식 문제를 요청받으면 해당 브리지의 상태와 표시 순서를 따른다.

## 첫 시범운영

`오늘 민법 과외 시작` 요청은 [교수법 정본](../rules/teaching-method.md)에 따라 강의 중심으로 진행한다. 최신 추천과 실제 진도를 확인하되 복습 대기열 완료를 신규 강의의 조건으로 삼지 않는다. 이해가 안 된다는 반응에는 질문을 멈추고 설명한다.

강의와 직후 이해 확인은 채팅에 남기고, 지연 회상과 공식 평가는 [기록 규칙](../rules/concept-recall.md)에 따라 구분한다. 실제 원답과 기록 조건을 확인한 범위만 추가하며 부분 답변을 단원 전체 완료로 확대하지 않는다. 확인되지 않은 학습시간이나 공식 문제 점수는 만들지 않는다. 기록 권한이나 연결이 없으면 학습을 진행한 사실과 기록하지 못한 상태를 구분해 알린다.

이번 준비 점검에서는 원본 셀을 쓰지 않았고 실제 학습이력도 만들지 않았다. 강의 파일의 최종 제작·근거 확인 상태는 교육과정 색인의 `lesson_status`와 각 강의의 출처 기록을 따른다.
