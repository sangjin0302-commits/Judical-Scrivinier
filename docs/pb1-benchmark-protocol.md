# PB1 성능·안전 인수시험

결과를 보기 전에 고정한 절차다. 운영 원본에서는 실행하지 않는다.

## 준비

- 동일한 테스트 사본과 동일한 활성 범위·문항수 사용
- 10문항, 총칙 3·물권법 7 설정은 최신 학습범위 확인 뒤 사용
- 기존 중계 방식과 v2 모두 새 시드 사용
- 각 경로 출제 5회, 채점 5회. 첫 실행은 냉시작으로 별도 표시
- 중앙값과 최소·최대, 실패 횟수 기록

## 시간 경계

- 출제: 사용자 실행 시점부터 문제 10개가 화면에 모두 보일 때까지
- 채점: 제출 시점부터 점수 표시와 세트관리 F=`예` 재검증까지
- Apps Script 내부 `timingMs.total`과 브라우저 체감시간을 함께 기록
- 기존의 4셀 1,038ms·456ms 측정은 참고 표본일 뿐 10문항 전체시간으로 사용하지 않음
- 사용자가 경험한 약 10분은 현상 보고이며 통제된 기준값으로 단정하지 않음

## 안전 시험

| 시험 | 합격 기준 |
|---|---|
| 후보 동등성 | 같은 범위·시드에서 기존 브리지 상위 N개와 전부 일치 |
| 키 보호 | 답안 전 채점키 읽기 0회; 제출 뒤 선택 40행만 읽음 |
| 기록 | A:G/A:L 값과 H/M 수식 모두 일치 |
| 동시 출제 | 같은 requestId 8회 동시 호출에 세트 1개 |
| 동시 제출 | 같은 답안 동시 호출에 안정키별 기록 1개 |
| 충돌 제출 | 다른 답안 재제출은 기록 없이 거부 |
| 복구 | 단계별 강제 실패 뒤 재시도하여 중복 없이 완료 |
| 원본 차단 | 운영 원본 ID로 실행 시 즉시 오류 |
