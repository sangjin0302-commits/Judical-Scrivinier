우선 적용 제안은 조회 묶음화와 파일 라우팅이다. 탭 삭제·원장 재구축·이력 이동·수식 재작성은 승인 대상이며 이번에 실행하지 않았다. 같은 업무를 같은 상태에서 전후 비교하기 전에는 성능 개선 완료라고 부르지 않는다.

## 분리 시험 계획

1. 정답 없는 합성 fixture로 상위 N 순서 보존, 상태 비정상 차단, 원답 없는 채점 차단, 중복 요청 거부, 입력열 허용 목록을 확인한다.
2. 현재 원본과 분리된 기존 테스트 사본의 사용 가능 상태를 확인한다. 과거 테스트 결과는 현재 재실행으로 표시하지 않는다.
3. 승인된 사본에서 동일 데이터·시드·답안으로 기존/제안 경로를 실행한다. 개인 원답 대신 합성 제출을 쓰고 테스트 표시한다.
4. 점수·후보 순서·기록행·복습일·수식·키 접근 로그까지 동일해야 원본 적용안을 제시한다.

이번에는 읽기 호출 묶음 비교와 합성 fixture 9개 검사를 수행했다. tests/test_safety_contract.py에서 상위 순서·비정상 상태·후보 부족·키 중복·미제출·답안 형식·보호열을 확인했다. 실제 Sheets 코드나 계산 결과의 동등성을 증명하는 시험은 아니다. 수식 최적화 및 쓰기 경로 시험은 미실행이다.
