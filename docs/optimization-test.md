## 로컬 합성 fixture

실행: `python tests/test_safety_contract.py`.

9개 테스트 통과: 표시 순서 유지, 비정상 상태 차단, 후보 부족 차단, 중복 키 차단, 미제출 차단, O/X 형식 검증, 정상 제출 허용, 보호열 차단, 허용열 통과.

fixture는 가상 K1/K2/K3와 O/X 형식만 사용한다. 실제 문제 지문·정답·개인 원답을 담지 않는다. 테스트의 작은 함수는 운영 자동화나 배포 코드가 아니다. 실제 Sheets 수식 및 PB1 코드의 안전성을 증명하지 않는다.

## 운영 지침 대조

고속 v2와 p1-ox 요약을 대조하여 기본 범위를 실제 학습 완료 누적 범위로 바로잡고, 기본 10문항·동적 비중·영역별 별도 세트·앞 묶음 좁은 채점키 조회 규칙을 반영했다. p2-case는 1차 비중 적용 없이 기존 사례그룹·소문항·배점·7요소·보호열 규칙을 유지한다.

## 추가 검증 필요

Apps Script 현행 코드와 호출 계약, 실제 동시 실행, 부분 실패 재시도, 제출/세트 중복 방지, Google 재계산 결과, 보호범위 권한은 별도 사본 시험이 필요하다. 신규 테스트 코드를 원본에 연결하거나 배포하지 않았다.
