# 과외 시범운영

## 준비

Private GitHub 연결에서 START.md와 작업 브랜치의 시범 lessons 파일이 읽히는지 확인한다. Drive/Sheets도 읽을 수 있어야 한다. 이 확인은 새로운 학습이력을 만들지 않는다.

## 한 번의 수업

사용자: `오늘 민법 과외 시작. 30분.`

ChatGPT는 오늘 학습 대상의 필요한 행을 확인하고 단원ID를 확보한다. 준비된 강의가 있으면 바로 해당 파일을 읽는다. 시범 단원과 실제 오늘 대상이 다르면 시범 제안임을 밝히며 이미 학습했다고 취급하지 않는다.

강의는 짧게 설명하고 사용자의 질문을 받는다. 책을 덮고 답하는 단계에서는 recall 파일만 제시한다. 답변 후 근거를 확인해 기억함·부분 기억·재복습으로 평가한다. 실제 원답·누락·근거를 개념 시트에 기록하며 강의를 읽은 사실만으로 독서나 회상 성공을 만들지 않는다.

사용자: `민법 1차 문제 10개.`

현재 브리지 상태와 설정을 확인하고 기존 후보 순서를 따른다. 개념 연계표의 문제를 임의로 끼워 넣지 않는다. 세트를 등록한 뒤 정답 없이 출제한다.

사용자가 답안을 내면 수와 형식을 확인하고 해당 키만 읽어 채점한다. 공식 기록을 묶음 추가한 뒤 반영을 확인한다. 오답의 필요한 기본서 페이지만 안내한다.

사용자: `오늘 학습 마무리.`

실제 완료한 수업·회상·공식 풀이와 미완료를 구분한다. 이미 기록한 활동은 재기록하지 않는다. 다음 복습일은 시트 계산 결과를 읽어 안내한다.

## 실패 상황

| 상황 | 동작 |
|---|---|
| GitHub 읽기 실패 | 실패 파일을 알리고 강의 내용을 추측하지 않음 |
| 강의 미제작 단원 | 준비 상태를 알리고 원문을 좁게 확인하거나 시범 단원 선택 제안 |
| 브리지 비정상 | 공식 신규 출제 중단, 이미 확인된 개념 설명 가능 |
| 답안 개수 불일치 | 키를 읽지 않고 필요한 답안 범위 확인 |
| 다른 세트로 선택키 변경 | 기존 세트와 일치 확인 전 채점·기록 중단 |
| 일부 저장 실패 | 실패 범위와 기록 대기 표시, 기존 성공분을 중복 쓰지 않음 |
| 회상 없이 설명만 완료 | 기억함·통과 판정 없음 |

실제 사용자와의 수업·답안·기록 종단 시험은 별도다. 이 문서는 운영 시나리오이며 시험을 수행했다는 보고가 아니다.
