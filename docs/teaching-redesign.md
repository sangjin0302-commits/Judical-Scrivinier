# 교수법 개편과 적용 계획

기준일: 2026-10-27. 이 문서는 수업 설계의 변경을 설명한다. 실제 사용자 답변이나 학습 성과를 보고한 문서가 아니다. 교수법의 세부 기준은 [교수법 정본](../rules/teaching-method.md)에 둔다.

## 바꾼 수업 흐름

기존 학습 경로는 강의 파일을 읽은 뒤 곧바로 회상 질문에 답하는 흐름이었다. 이를 오늘학습 대상 확인, 짧은 복습, AI 핵심강의, 사례 설명, 이해 확인, 공식 문제, 부족한 법리 재강의, 다음 진도 순서로 고쳤다. 복습 대기열 전체 완료를 신규 학습의 조건으로 삼지 않는다.

| 항목 | 기존 흐름에서 생길 수 있던 문제 | 이번 적용 기준 |
| --- | --- | --- |
| 수업 시작 | 복습 항목을 모두 처리하다 신규 진도가 늦어질 수 있음 | 실제 대상을 확인하고 짧은 복습 1~2개 뒤 핵심강의로 이동 |
| 개념 설명 | 요약을 읽고 바로 기억 여부를 물으면 이해의 빈틈을 놓침 | AI가 개념과 사례를 설명한 뒤 이해 질문 1~2개로 확인 |
| 오답 후 진행 | 질문을 반복해도 왜 틀렸는지 모를 수 있음 | 실제 답변에서 드러난 부족한 법리만 다시 가르침 |
| 학습 판정 | 강의를 들은 직후 답한 것을 장기 기억으로 오인할 수 있음 | 즉시 이해와 지연 회상을 구분하고 각각 실제 답변으로 판단 |
| 진도 관리 | 예정 시간이나 자료 제작을 학습 완료로 오인할 수 있음 | 실제 학습 범위를 확인하고 다음 진도를 정함 |

[시범 수업](teaching-demo.md)은 위 차이를 대화 순서로 보여준다. 설명과 사례를 먼저 제공하고 질문 뒤에는 사용자의 답변을 기다린다. 예시 답변은 수업 설명을 위한 가상 자료이며 실제 원답으로 기록하지 않는다. 공식 문제의 정답·해설 공개 시점과 기록 규칙은 기존 브리지 절차를 유지한다.

## 현재 7단원에 적용

우선 `B1-P0040-0047`, `B1-P0072-0079`를 개편 대상으로 삼는다. 기존 자료의 확인 범위를 유지하며, PDF 대조를 하지 못한 부분은 완료로 표시하지 않는다. 나머지 기존 5단원은 해당 단원을 다음에 가르칠 때 개편한다. 강의·회상 파일과 기존 단원ID는 유지한다.

수업을 고칠 때는 설명 없이 암기만 요구하는 부분이 있는지, 사례에서 적용 이유를 설명하는지, 질문 뒤에 실제 답변을 기다리는지 확인한다. 세부 교수법을 각 문서에 복제하지 않고 정본을 참조한다. 모든 단원을 한꺼번에 다시 작성하지 않는다.

다음 표는 기존 5강의 향후 개편 계획이다. 이번 작업에서는 이 5개 강의 파일을 수정하지 않았다. 아래 사례는 수업 방향이며, 실제 작성할 때 해당 범위의 근거를 확인한다.

| 단원 | 다음 개편에서 확인할 내용 |
| --- | --- |
| 민법의 의의 | 매매와 소유권의 관계를 한 사례의 시작부터 결론까지 설명하고 용어만 나열한 부분을 보완 |
| 민법의 법원 | 반복된 관행과 법적 확신을 구별하는 사례로 이해 확인 |
| 민법의 기본원리 | 상대방을 신뢰하기 전후에 지출한 비용을 비교하는 사례로 설명 순서 점검 |
| 민법의 해석 및 효력범위 | 일상어로 이해한 내용을 법률 용어로 다시 표현하게 하여 의미 차이 확인 |
| 법률관계와 권리·의무 | 당사자의 청구와 항변을 대화로 구성하고 각 주장에 필요한 설명 보완 |

## 나머지 233단원의 준비

| 시점 | 준비할 내용 | 진행 조건 |
| --- | --- | --- |
| 오늘학습 대상 확인 | 원본의 실제 단원ID와 필요한 범위 확인 | 개인 원답·세부 이력을 GitHub에 복제하지 않음 |
| 수업 전 | 해당 범위의 검색용 Markdown 확인, 필요한 PDF 대조, 법리의 현행 근거 검토 | 접근하지 못한 자료와 미확인 부분을 명시 |
| 강의 준비 | 정본에 맞춰 핵심 설명·사례·이해 질문 구성 | 해당 단원만 작성하고 기존 질문ID와 새 연습 질문을 구분 |
| 수업 진행 | 실제 답변에 맞춰 부족한 설명 보완 | 실제 회상 원답 없이 회상 평가·기억 성공을 만들지 않음 |
| 수업 후 | 준비한 파일의 경로·출처·상태 점검 | 자료 준비와 사용자 학습 완료를 구분 |

233단원은 적시에 준비할 대상 수다. 지금 상세 강의가 완성되었다는 뜻은 아니다. 학습시간 제안은 분량 조절에만 쓰며, 속도 향상이나 합격·기억 유지 효과를 측정한 결과로 제시하지 않는다. 이후 실제 수업에서 설명에 걸린 시간과 이해 질문의 답변을 확인해 다음 분량을 조절한다.

## 기록과 검증 범위

기존 240개 단원ID, 공식 문제 안정키, 원본 수식과 채점 절차를 유지한다. 즉시 이해 확인을 지연 회상 성공으로 기록하거나 개념 연습 결과를 공식 점수로 바꾸지 않는다. 실제 회상 원답을 받은 경우에도 지정된 기록 위치와 조건을 확인한 뒤 기록한다. 독서는 사용자가 실제로 읽었다고 확인한 내용을 기존 규칙에 따라 기록한다.

이번 개편의 확인 대상은 수업 흐름과 자료의 연결이다. 구조 검사가 통과해도 미검증 문제 연결이나 미대조 원문이 검증 완료로 바뀌지는 않는다. 사용자 성취는 실제 수업 이후에만 판단한다.

## 실제 ChatGPT에서 적용하기

이번 변경은 PR 작업 브랜치의 파일에 반영한다. 기존 ChatGPT 프로젝트 설정 자체를 자동으로 바꾸지는 않는다. 프로젝트에 붙여 둔 시작 지침이 이전 버전이면 [새 시작 지침](../PROJECT_INSTRUCTIONS.md)으로 갱신하고, 병합 전에는 `feat/civil-tutor-phase1`을 읽도록 한다. 이전 대화의 복습 우선 흐름이 남아 있으면 교수법 정본을 다시 읽고 새 흐름으로 시작한다.

다음 실제 수업에서 확인할 것은 첫 강의의 설명·사례가 질문보다 충분히 제공되는지, 이해가 안 된다는 응답에 다른 설명을 제공하는지, 복습 대기열과 무관하게 신규 진도가 진행되는지다. 자동 검사는 문서·식별자 무결성을 확인하며 ChatGPT의 실제 응답 준수나 학습효과를 입증하지 않는다.
