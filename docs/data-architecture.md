# 자료 배치와 원본 책임

기준일 2026-10-27. 이번 구성은 기존 ChatGPT 과외를 지원하며 서버·웹앱·유료 API를 추가하지 않는다.

| 영역 | 원본 | GitHub 보관 범위 | 일상 조회 |
|---|---|---|---|
| 운영 지침 | 확인한 프로젝트 v3·고속 v2 | 원문 버전 사본과 짧은 작업별 요약 | START와 해당 규칙 |
| 교재 | Drive 단기 민법·로앤 | 출처·페이지·독립 작성 강의 | 단원 강의, 필요 시 교재 일부 |
| 개념 진도 | 개념 Google Sheet | 개인 진도 없는 240단원 정적 색인 | 오늘 학습 및 해당 단원 |
| 개념 평가 | 개념_회상이력 | 평가 방법만 | 실제 원답 추가·확인 |
| 공식 문제 | 문제 Google Sheet | 확인된 연결키·출제 절차만 | 브리지 선택 범위 |
| 공식 채점키 | 문제 Google Sheet | 값·원문 복제 없음 | 답안 이후 해당 선택 행 |
| 문제 갱신 자료 | Google Docs 3개 | 문서ID·검토 절차 | 변경 감지 및 승인된 유지보수 시 |

GitHub의 정적 색인은 원본 시트와 자동 동기화되지 않는다. 변경 시 원본 행과 버전을 비교한 PR을 만든다. 개인 진도는 색인에 저장하지 않으므로 GitHub 버전만으로 오늘의 진도를 결정할 수 없다.

## 연결과 접근

저장소는 `sangjin0302-commits/Civil-law-2027`로 이름이 변경되었다. 사용자가 초기 구축의 Public 게시를 허용했고 완성 후 직접 Private 전환 예정이라고 했다. Private 전환 후에는 ChatGPT GitHub 연결에 접근 권한이 있어야 한다. 이번 Codex의 읽기 성공은 다른 기기의 ChatGPT 접근 성공을 보증하지 않는다. 최초 사용 시 START와 시범 강의 1개를 실제 읽는지 확인한다. Draft PR은 작업 브랜치를 지정하고, 승인 병합 이후 main으로 전환한다.

Drive/Sheets 접근 권한도 유지한다. GitHub 접근만으로 원본 시트를 읽거나 기록할 수 없다. 연결 실패 시 현재 확인 가능한 자료로만 설명하고 공식 기록 완료라고 하지 않는다.

## 현재 범위

원본 구조 변경, 자동 증분 적용, Apps Script 배포, 교재 대량 업로드는 하지 않는다. 기존 PB1 등 보조 자동화는 이전 작업과 현행 계약을 확인해 재사용 가능성을 판단한다. 새 프로그램을 개발하거나 활성화한 것으로 설명하지 않는다.
