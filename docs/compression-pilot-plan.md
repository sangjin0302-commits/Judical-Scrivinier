# 압축 수업 비교 실험안

기준일: 2026-10-27. 아직 실험하지 않았다. 시간 절감률·정답률·기억 유지 성과는 미측정이다.

## 비교 범위

같은 시험 역량을 익히는 데 걸린 총시간과 이후의 적용 능력을 비교한다. 직접독서는 정한 범위의 기본서를 읽고 재독·문제풀이·교정을 진행한다. AI 수업은 [논점 지도](../curriculum/issue-map.csv)의 A를 배우고 사례에 적용한 뒤 필요한 B를 보충한다. C는 근거를 확인한 배경 논점을 조건부로 유예하며, 새 예외나 확인하지 않은 원문을 자동으로 C에 넣지 않는다.

현재 7단원만 논점 수준으로 분류했다. 나머지 233단원은 미분류다. A의 근거는 필수 선수 관계 또는 실제 문제에서 확인한 요구이며 출제빈도 등급이 아니다. 직접 문제 관찰과 교육설계상 추론은 [시험 요구 분석](exam-demand-evidence.md)에서 구분한다. 이 시범만으로 전체 시험 역산을 완료했다고 보지 않는다.

## 비교 조건

같은 내용을 두 번째 배울 때 생기는 이점을 줄이도록 사전지식, 논점 수, 요건·예외의 복잡도가 비슷한 두 범위를 짝짓는다. 한 범위는 직접독서, 다른 범위는 AI 수업으로 진행하고 다음 짝에서는 방식의 순서를 바꾼다. 같은 단원을 순서대로 재학습한 시간만으로 우열을 판단하지 않는다. 동등한 범위를 확보하지 못하면 참고 관찰로만 해석한다.

시작 전에 사전지식을 짧게 확인하고 최근 풀어 본 문항을 표시한다. 사전 질문의 학습 효과도 양쪽에 같은 조건으로 적용한다. 직후 평가와 지연 평가에서는 같은 요건·예외를 다른 사실관계로 묻는 동등한 문항을 쓴다. 문항 동등성은 글자 수만으로 판단하지 않는다. 지연 간격, 허용 자료, 판정 기준은 실험 전에 정한다.

기존 복습일과 자동수식은 바꾸지 않는다. 가능한 범위에서 같은 지연 간격의 결과를 비교하고, 간격이 다르면 그 차이를 별도 한계로 보고한다.

공식 브리지의 후보 순서를 바꾸지 않는다. 동등한 공식 평가를 구성하지 못하면 공식 결과는 별도 관찰로 두고 비교용 창작 연습을 공식 점수와 분리한다. OX는 1차 대비 학습 형식이며 실제 객관식 시험과 같다고 보지 않는다. 정답과 채점키는 실제 답안 제출 후 기존 절차에 따라 확인한다.

## 측정 항목

### 실제 수업의 예상과 관찰

아래 A~E는 운영 장면의 이름이며 논점 등급 A·B·C와 다르다. 예상 동작을 먼저 정하고, 실제 동작·시간·원답은 수업 이후 채팅에만 채운다. 현재는 모두 미실행이므로 실제 결과 칸을 비워 둔다.

| 장면 | 예상 동작과 점검 기준 | 실제 동작·시간·관찰 | 판정 |
| --- | --- | --- | --- |
| A 신규 학습 | `오늘 민법 과외 시작` → 오늘의 실제 대상을 확인하고 긴 복습 목록 대신 1층 핵심 구조·완결 사례를 설명한 뒤 질문 하나를 제시하고 대기 | | |
| B 이해 실패 | `아직 이해가 안 돼` → 같은 질문을 반복하지 않고 해당 2층의 다른 설명과 사례로 다시 가르친 뒤 짧게 확인 | | |
| C 정확한 설명 | 확인한 논점만 이해됨으로 보고 미확인 A가 남았는지 점검한 뒤 다음 논점이나 공식 문제로 이동 | | |
| D 공식 문제 | 공식 OX 또는 2차 사례 요청 → 브리지 상태·순서·세트 기록을 지키고 실제 답안 제출 후에만 해당 채점키 조회·채점. PB1 호출 없음 | | |
| E 마무리 | 강의 청취·직후 이해·지연 회상·공식 점수를 구분하고 실제로 다룬 범위·남은 논점·다음 진도를 정함. 실제 원답 없는 성공 기록 없음 | | |

실행하지 않은 장면은 성공으로 표시하지 않는다. 미실행·미측정 값은 빈칸으로 남기며, 예정 동작과 실제 관찰이 다르면 원인을 적어 재설계한다.

### 결과를 보기 전에 고정할 탐색 기준

아래는 사전계획 v1.0의 기본 판정 기준이다. 소규모 운영의 확대 여부를 판단하는 탐색 기준이며 합격 기준이나 효과가 검증된 임계값은 아니다. 첫 비교 전에 대상 쌍·문항·평가표·허용 자료·시작일을 채팅에 고정한다. 결과를 본 뒤 기준을 소급하여 바꾸지 않으며 변경은 다음 비교부터 새 버전으로 적용한다.

- 서로 다른 유사 난도 범위를 최소 2쌍 준비해 직접독서 우선과 AI 우선의 순서를 교차한다. 사전지식 차이가 확인되거나 문항 동등성을 설명하지 못하는 쌍은 효율 비교에서 제외하고 관찰만 남긴다.
- 각 쌍에서 동일한 평가 분량·힌트 조건을 적용한다. 직후 이해, OX, 2차의 쟁점·법리·포섭, 3일·7일 관찰 점수가 직접독서보다 낮지 않고 필수 논점 누락이 0일 때만 다음 확대를 검토한다. 나머지 2차 평가 요소도 함께 보고한다.
- 각 동등한 쌍의 절감률을 `100 × (직접독서 총시간 - AI 총시간) / 직접독서 총시간`으로 계산하고 그 중앙값을 사용한다. 직접독서 시간이 0이거나 어느 쪽이든 미측정이면 계산하지 않는다. 중앙값 10% 이상을 다음 소규모 확대를 검토할 시간 절감 신호로 정했다. 대기·문제풀이·피드백·재강의·보충을 모두 포함하며, 준비 비용은 별도 제시한다. 10%는 실용적 차이를 보기 위한 탐색 기준일 뿐 검증된 효과 크기나 합격 기준이 아니다.
- 능력 저하, 필수 논점 누락, 비교 조건 불일치, 지연 관찰 누락 중 하나라도 있으면 확대 판단을 보류한다. 필수 누락은 A에 복원하고 재강의·재측정한다. 시간이 줄지 않으면 설명·조회·대기 중 어디서 시간이 쓰였는지 나누어 재설계한다.

3일·7일 평가는 연구용 관찰이다. 기존 시트의 복습일·간격 수식을 변경하지 않는다. 같은 경과일에 관찰할 수 없으면 실제 경과시간을 표시하고 비교 한계로 남긴다. 그 사이 추가 복습 여부도 채팅에서 확인하며, 조건이 달라졌다면 동등한 지연 비교로 취급하지 않는다. 현재 두 쌍, 평가 점수, 소요시간, 누락 개수 모두 미측정이다.

| 항목 | 비교 방법 |
| --- | --- |
| 학습자 총시간 | 직접독서의 첫 독서·재독과 AI의 강의·질문응답 시간을 각각 재고, 양쪽 모두 문제풀이·피드백·재강의·교정·보충 독서·대기·재시도를 합산 |
| 준비 비용 | 자료 생성·근거 확인·평가 준비 시간은 학습자 시간과 별도로 보고 |
| 직후 이해 | 같은 조건에서 설명과 새로운 사실 적용을 확인 |
| 지연 회상 | 3일·7일의 같은 경과시간과 자료 제한 아래 실제 원답으로 확인하고 불일치는 별도 표시 |
| 1차 적용 | OX 결과와 틀린 조건·예외를 확인하고 객관식 선택지 구별도 별도로 점검 |
| 2차 적용 | 같은 배점·기준으로 쟁점·목차·법리·판례·포섭·결론·표현을 구분 |
| 누락 검토 | 교재·공식 요구와 대조해 누락한 요건·예외·판례 한계를 찾고 보충시간까지 합산 |

실제 회상 원답 없이 회상 평가나 기억 성공을 만들지 않는다. 독서는 사용자가 실제로 읽었다고 확인한 범위를 기존 규칙에 따라 기록한다. 창작 연습을 공식 성적으로 저장하거나 개인 원답을 GitHub에 복제하지 않는다.

채팅 측정 양식: `단원/논점: | 방식: | 사전지식: | 직접독서 분: | AI설명 분: | 대기/문제/보충 분: | 직후 원답/힌트 여부: | OX 맞음/총수: | 2차 쟁점·법리·포섭: | 지연일/원답: | 누락 논점:`

측정하지 않은 칸은 빈칸으로 둔다. 이 양식에 실제로 채운 개인 원답·시간·성취 내용은 채팅에서 다루며 GitHub에 저장하지 않는다.

시간은 최초 학습 시작부터 평가·피드백·보충 종료까지 실제 시각으로 잰다. 무관한 휴식·중단은 따로 표시해 제외하고, 수업에 필요한 조회·생성 대기는 포함한다. 직접독서·AI설명 읽기·답변작성·대기·피드백·보충 구간은 겹치지 않게 기록해 두 번 더하지 않는다. 초기 총시간과 3일·7일 관찰·재보충 시간을 각각 남기고, 확대 판정의 총시간에는 두 지연 관찰까지 더한다. 단계를 따로 재지 못하면 전체 실측시간만 보고하고 항목별 시간을 추정하지 않는다.

운영 관찰은 `통과 / 수정 필요 / 미실행`으로 구분한다. 응답만 보아 실제 채점키 접근 시점을 확인할 수 없으면 D의 접근 항목은 미확인으로 남기고 도구 실행 내역이 있는 경우에만 확정한다. 설명이 그럴듯하다는 이유로 안전 절차까지 통과했다고 판정하지 않는다.

## 후속 판단

총시간이 줄어도 핵심 요건이나 예외를 빠뜨렸다면 그대로 확장하지 않는다. 필수 논점의 누락이면 A로 승격하고, 그 밖의 적용상 부족은 B로 보충한다. 추가 학습시간까지 포함해 판단한다. 직후 이해가 좋아도 지연 회상이나 새로운 사실관계의 적용이 부족하면 숙달로 보지 않는다. 시간이 줄었더라도 능력이 저하되었거나 비교 조건이 동등하지 않으면 효율이 입증되었다는 판단을 보류한다. 결과를 본 뒤 유리한 허용 오차나 기준을 만들지 않는다.

비교 순서·사전지식·문항 동등성의 한계를 함께 보고한다. 적은 수의 단원으로 240단원 전체의 시간 절감이나 합격 가능성을 일반화하지 않는다. 우선 7단원 운영을 확인하고 나머지 단원은 실제 학습 대상이 되었을 때 하나씩 분류한다.
