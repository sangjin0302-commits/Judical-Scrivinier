기준일 2026-10-27. 원본 시트 변경 없음. 이 결과는 학습자료 구축과 읽기 전용 진단이며 실제 사용자 학습·공식 채점 완료 보고가 아니다.

- START·PROJECT_INSTRUCTIONS·MANIFEST와 작업별 규칙: 일상 학습에서 필요한 파일만 읽는 경로.
- 기존 240단원 색인: 1권 96개·2권 144개. 나머지 235단원 상세 강의는 미제작.
- 첫 5단원 강의와 별도 회상 질문. 교재 표본 PDF 및 관련 법령·판례 확인 범위는 pilot-report.md.
- 단기 민법·로앤 대응표. 직접 본문 대응과 목차만 확인한 대응을 구분.
- 기존 연계 21건 보존: 20건은 15단원에 연결, 1건은 원본 단원ID 공란 그대로 검토 필요. 공식 원장 안정키 재확인·전체 법리 대응은 미실시.
- 두 시트 45개 탭 역할·수식 표본·의존관계·경량화 및 복구 설계.
- Google Docs 증분 갱신 설계. 자동 반영은 활성화하지 않음.

## 유지할 기능

공식 문제·채점키·출제 브리지·세트관리·풀이 및 채점 이력, 개념 단원ID·실제 원답·평가·복습 수식은 기존 원본에 남긴다. GitHub로 설명을 옮겼다는 이유로 원본 탭을 삭제하지 않는다.

## 성능과 검증의 범위

같은 4셀의 조회를 분리 2회와 묶음 1회로 비교한 3회 표본 중앙값은 1038ms와 456ms였다. 별도의 값 대조는 4/4 일치했다. 56.1% 감소는 이 조회 경로에 한정하며 실제 출제·채점 전체 개선율이 아니다.

합성 안전 계약 검사 9개, 패키지 무결성 검사 855개가 통과했다. 패키지 검사는 단원ID·파일쌍·페이지 범위·연계·필수 문서·내부 링크를 확인한다. 게시 대상 50개 파일의 원문 바이너리·접근키 패턴 검사에서도 발견사항이 없었다. 이 검사는 법리 정확성, Google 수식 재계산, 실제 쓰기, 학습효과를 증명하지 않는다.

## 원본 적용 전 남은 일

1. 기존 PB1 통합 함수의 현행 코드·권한·호출 계약을 확인한다. 과거 배포 보고만으로 현재 실행 성공을 가정하지 않는다.
2. 수식 변경은 분리 사본에서 같은 후보 순서·기록행·복습 판정을 확인한다. 원본 적용은 별도 승인과 백업 후 진행한다.
3. 다음 기록행 검색, 회상 FILTER 반복, 2000행 문항 집계 경계를 추가 검증한다. 현재 수식은 변경하지 않았다.
4. 공식 연결의 공란 1건과 검토 대기 상태를 좁은 원문 확인으로 해결한다. 임의 ID를 채우지 않는다.
5. 실제 사용자 답안을 이용한 시범 수업과 기록은 후속 학습 요청에서 수행한다. 가짜 답안으로 원본 성능 측정을 하지 않는다.
6. 교재의 91다46885 관련 설명과 확인한 실제 판시사항 사이의 차이를 검토한다. 시범 강의는 실제 판결의 사경제 계약·감액/환수 특수조건 범위로 교정했으며 교재나 공식 정답은 바꾸지 않았다.
