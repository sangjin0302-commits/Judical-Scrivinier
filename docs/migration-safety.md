# 원본 적용 전 안전 계획

이번에는 원본 탭 삭제·수식 변경·이력 이동·스크립트 배포를 실행하지 않았다. 아래는 후속 적용 조건이다.

## 백업

원본 변경 전에 native Google Sheets 사본, 대상 수식·설정·보호범위·검증 규칙, Apps Script 코드와 트리거·배포 버전을 비공개로 보존한다. xlsx 재업로드를 복구 방법으로 쓰지 않는다. 백업은 실제 열림과 표본 수식까지 확인한다.

## 검증

안정키/단원ID/후보 순서/세트별 번호/자료 기준시각/다음 빈행/원답/점수/복습일을 비교한다. OX정답키 H, 풀이이력 M:Q, 서술형채점 G/O:Q 및 개념 자동열의 수식을 비교한다. 원답 없는 성공, 가짜 학습, 사전 키 조회는 금지한다. 권한 오류·부분 실패·중복 제출·동시 실행·상한 초과를 포함한다.

## 적용

변경 목록·시험 결과·차이·복구 방법을 검토한 뒤 별도 사용자 승인으로 원본에 적용한다. 초기에는 1개 경로만 전환한다. 코드/수식 버전과 적용시각을 남기고 신규 기록을 검증한다. 공식 진행·통과·졸업 상태는 직접 수정하지 않는다.

## 실패와 복구

새 요청을 중지하고 기존 경로로 돌아간다. 수식·설정은 확인한 백업 버전으로 복구하되, 적용 후 발생한 정상 학습이력은 보존한다. 통합문서 전체 덮어쓰기나 이력 행 삭제로 되돌리지 않는다. 부분 기록은 세트ID·안정키로 조회하여 부족한 항목만 승인된 복구 절차로 처리하고, 성공 여부가 불명확하면 재실행보다 대조를 먼저 한다.

개인 풀이이력·채점키·교재 원문을 GitHub 백업에 넣지 않는다. GitHub에는 변경 설계와 비민감 검증 결과만 남긴다.
