## 같은 범위 조회 비교

1차 B5와 B11:B13, 표시값 4셀. 분리: get_spreadsheet_range 2회 순차. 묶음: get_spreadsheet_cells 1회, formattedValue 필드. 3회씩 교대로 실행했다. 응답 포장 형식은 다르므로 전송량까지 완전히 통제된 실험은 아니다.

이 제한 표본에서는 묶음 조회 중앙값이 582ms(56.1%) 짧았다. 이는 네 셀 조회 경로의 관측 결과이며 출제·채점 전체가 56.1% 빨라졌다는 뜻이 아니다. 표본 수가 작고 캐시·네트워크 순서 효과가 있다.

측정 후 같은 4셀을 분리/묶음 방식으로 한 번씩 다시 읽어 표시값 배열을 비교했다. 4/4 일치했다. 측정 3회 각각의 값 비교 로그는 남기지 않았으므로 모든 회차의 값 동등성을 검증했다고 주장하지 않는다. 이 대조도 추가 쓰기 없이 수행했다.

개선 전 단계 계측 1회(총 55.280초)는 기존 기록 검색 23.904초, 최종 전체 이력 재검색 25.806초로 두 전체 스캔이 49.710초였다. 잠금 대기 0.128초, 세트 조회 2.404초, 선택 채점키 준비·조회 0.563초였다. 최적화 후 정상 5회의 기존 기록 조회는 0.045~0.366초, 최종 제한 행·수식 검증은 5.219~6.308초였다.

정상 제출은 쓰기 전 예약에 세트·OX·풀이이력 행 위치를 기록하고 해당 10행만 읽는다. 오래된 예약이나 행 포인터가 없는 실패 상태는 전체 이력 안전 스캔으로 후퇴한다. 누락 행 복구는 기존 행을 지우지 않고 새 행만 추가한다. 따라서 120초 잠금 확대를 성능 개선으로 계산하지 않았다.
