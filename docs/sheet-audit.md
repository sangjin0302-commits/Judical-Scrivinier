## 관찰된 계산 의존관계

3. 2차 A17 → 같은 탭 AG17:AR516 사례 보조영역. 내부 수식 전체 및 그룹 생성 과정은 추가 조사 필요.

## 부하 판단

실제 느린 계산 탭은 이번 조회만으로 확정하지 못했다. 우선 조사 후보는 1차 후보 정렬, 개념 단원별 회상 FILTER 반복, 열린 다음 기록행 검색이다. 이력 탭의 큰 할당 행수 자체는 삭제 근거가 아니다. 정적 지침·색인의 GitHub 제공은 ChatGPT 전송량을 줄일 수 있지만 시트 계산 성능 개선으로 측정된 것은 아니다.

## 유효 범위와 확장 경계

- 개념 단원 계산의 고정 범위는 5:244행(240개), 전용문항 집계 참조는 5:2000행. 미래 2000행 초과 시 누락 가능성을 별도 검증해야 한다.
- 공식 원장 주요 계산은 5:20004행. 실제 활성 문항 수/마지막 행은 이번에 전수 측정하지 않았다.
- 다음 기록행은 실시간 브리지 포인터이며 실행 직전 재확인한다. 보고서의 과거 숫자를 쓰지 않는다.
- 대부분 탭의 실제 유효 마지막 행, 빈칸 중간 누락, 전체 수식 개수는 미확인. 원답·정답 보호 때문에 무차별 추출하지 않았다.
