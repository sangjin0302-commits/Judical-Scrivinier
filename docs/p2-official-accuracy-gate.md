# 2차 공식 채점 정확성 관문

상태: **미통과**. 2026-10-29 기존 Railway 테스트 DB의 PREPARED 세트 원답을 읽기 전용으로 확인하고, `prepareCivilP2Grade`의 멱등 재호출로 해당 공식 모범답안·채점기준을 원답 확정 이후에만 조회했다. 원답·상태·점수는 변경하지 않았다. 채점기준·원답 전문은 이 문서에 기록하지 않는다.

해당 공식 소문항의 최대 배점은 15점. 공식 기준 텍스트에는 핵심요소별 숫자 배분이 명시되지 않는다. 그러므로 핵심요소 일치 **건수 비율**을 공식 점수로 환산하거나 7요소 평정 합계로 임의 환산하면 안 된다. 실제 원답 `모르겠다.`는 의미 있는 답안 요소가 없으나, 검증된 전체 요소 분해와 점수 근거가 확정되기 전에는 `commitCivilP2Grade`를 호출하지 않는다.

## 통과 조건

1. 공식 모범답안·채점기준에서 필수 쟁점·법리·요건·포섭·결론을 중복 없이 추출한다. 각 항목에 공식 원문 발췌 위치와 필수성 근거를 남긴다. 기준에 없는 판례·가중치·배점을 만들지 않는다.
2. 실제 원답과 함께 완전 정답, 동의어·대체 표현, 부분 답안, 결론만 정답, 포섭 오류, 반대 법리, 무응답의 합성 답안 최소 6종을 동일 기준으로 두 차례 평가한다. 합성 답안은 학습 성적으로 저장하지 않는다.
3. 독립 검토자가 각 항목의 의미 판정과 공식 배점 근거를 대조한다. 같은 답안의 재평가가 달라지면 기준을 고치고 다시 시험한다.
4. 검증된 평가만 격리 PostgreSQL에 기록해 원답 불변·멱등 재시도·변경 평가 거부·부분 실패 롤백을 확인한다. 그 뒤 실제 사용자 답안에 대한 기록 여부를 결정한다.

현재 자동시험은 근거 발췌 존재, 7요소 값 범위, 원답 불변 경계, 정확한 무응답의 전 요소 누락·0점, 부분 답안의 무응답 오분류 방지를 검사한다. 이는 **형식과 안전성** 검증이며 의미 판정·배점 정확성의 증명은 아니다.
