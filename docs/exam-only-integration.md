# 문제 전용 통합 현황

기준: `origin/main`에서 새 `integration/civil-exam-only` 브랜치. 기존 PR #1(개념 교수법)·#2(고속 출제)·#4(PostgreSQL 통합)을 통째로 병합하지 않는다. PR #3 book-to-skill은 별도 유지한다. 검증된 공식 문제·인증·DB·Docs 코드만 선택적으로 가져왔다.

## 운영 경계

- WorkOS 인증 MCP 사용자 도구는 P1 출제·채점, P2 출제·원답 확정·채점기록 **5개**와 공식 문제 진행 조회 **1개**다.
- Docs 대조·증분 미리보기와 변경 후보 기록은 기존 유지보수 토큰으로 보호한 POST 경로. 후보 기록은 자동 승인·문제 반영을 하지 않는다. 승인 없는 11건 내용 차이는 적용하지 않는다.
- 런타임은 `MCP_DATA_BACKEND=postgres`만 허용한다. 설정 누락 시 실패하며 Apps Script·Sheets 경로로 되돌아가지 않는다.
- 기존 Railway DB의 개념 테이블·학습기록, 공통 문제·세트·원답·성적 테이블은 삭제하지 않는다. 새 브랜치에서 개념 사용자 기능 코드만 제외한다.

## main 병합과 운영 전환의 차이

코드 PR 검사는 자동시험·빌드·비밀정보·기존 기능 회귀를 확인한다. 과거 Sheets 시드·정렬·할당량은 새 출제의 기준이 아니다. 실제 운영 전환은 새 PostgreSQL 출제 규칙, 실제 원답의 모범답안 의미요소 비율 채점, Docs 승인 변경 적용·롤백, 데이터/백업 대조, WorkOS·ChatGPT 종단 호출을 통과해야 한다.

## 현재 확인된 차단조건

- PostgreSQL 출제는 기본 1차 10문항, 요청 시 1~40문항·범위·취약·안정키 지정, 2차 사례 1~20개와 전체 소문항 확장을 지원한다. 기존 시트 순서 재현 코드는 제거했다. 격리 PostgreSQL 18에서 실제 SQL·전체 흐름 시험 통과. 기존 Railway 문제은행의 사례 키·버전·정답키 분포와 실제 처리시간 확인은 남았다.
- P2는 중복 없는 필수 의미요소별 완전·부분·불일치 판정으로 학습용 비율 점수를 계산한다. 7요소는 별도 진단이다. 실제 PREPARED 원답은 보존하며, 의미 판정 정확성 확인 전 채점 완료로 바꾸지 않는다.
- 새 통합 브랜치의 P2 채점 기록은 기본 차단이다. 모범답안 의미요소 판정의 인수시험을 통과한 테스트 배포에만 `P2_GRADE_COMMIT_ENABLED=true`를 설정한다. 기존 배포의 설정은 변경하지 않았다.
- Docs 본문 차이 11건은 사용자 승인 없이 적용하지 않는다. 합성 신규·수정의 격리 DB 적용·멱등·롤백은 통과했다. 실제 Docs 변경 후보 기록 경로는 구현했으나 Railway 호출과 승인된 실제 변경의 반영 시험은 아직 하지 않았다.

## 격리 DB 인수시험

2026-10-29 임시 PostgreSQL 18에서 합성 문제만 사용했다. 1차 2문항 출제·정답 채점·멱등 재시도, 2차 1사례 2소문항 동시 출제·원답 확정·AI 비율 점수 15/0 기록·재시도, 소유권/변경 답안 거부가 통과했다. Docs 신규/수정 승인 적용·이전 문제 버전 보존·충돌 롤백도 통과했다. 임시 컨테이너와 DB는 제거했다.

로컬 합성 12회 p50/p95(ms): 1차 출제 7.82/14.40, 1차 채점 14.86/25.90, 2차 출제 7.65/14.46, 2차 원답 확정·기준 조회 9.53/13.41, 2차 기록 13.51/16.04. AI 의미 판정·ChatGPT 네트워크 시간과 실제 Railway 부하는 포함하지 않는다.

기존 독립 테스트 Railway DB 읽기 전용 집계: P1 9,332건 중 게시 8,216건, P2 113건 모두 게시. 게시 문제의 검증된 활성 채점키는 각각 8,216/113건이며 현재 원문 버전 누락 0건. P2 키 형식 불일치 0건, 29사례 모두 복수 소문항(최대 9개). 실제 후보 SQL은 P1 기본 10개, P2 기본 1사례 3소문항, 특정 키 재조회도 통과했다. 원격 DB 조회 포함 선택 시간 12회 p50/p95(ms): P1 572.57/602.53, P2 336.15/356.35. 이 값은 출제·AI·ChatGPT 전체 지연시간이 아니다.

운영 전환 후 계획: 기존 문제 Sheets는 데이터·수식·탭을 유지한 **읽기 전용 보존본**으로, 개념 Sheets는 **비활성 보존본**으로 관리한다. 이 계획은 전환 승인 전 기존 파일 권한·내용을 변경하지 않는다.
